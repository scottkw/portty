## Decisions recorded

### ErrCopy vs ErrMount for the app-size failure
`StageFrom` maps an `AppSize` error to `installErr(ErrCopy, "app-size")` (step name kept). `AppSize` reads the copy source, which is already mounted on the update path and is the volume the user opened on the mover path. "Portty couldn't copy the new version." is accurate on both; "Portty couldn't open the download." (ErrMount) would wrongly suggest a mount failure. Before this change the update path said ErrMount and the mover said ErrCopy; no test pinned either.

### IsDir semantics
`isRealDir` (app_install.go) and updater's `isDir` were both `os.Lstat` plus `fi.IsDir()`, so a symlink is false in both. Identical, nothing stricter to preserve, merged as is into exported `updater.IsDir`.

### Bug (d) discrimination rule (the sweep's newer-than-installed rule)
For each stale `.Portty-update-*` dir whose `Portty.app` is a real dir, the sweep first checks, before any tool runs, that a real `Portty.app` exists in the same parent (so a parent with no installed copy runs no plutil). Only then does it read both `CFBundleShortVersionString` values via `updater.InstalledVersion` (10 s context, never runs the app). If both reads succeed and `Compare(staged, installed) > 0`, the copy is Portty's own new copy that never went in or was swapped back, and the staging dir is deleted. Every other case falls back to the recoverable Trash exactly as before and is never deleted: no installed copy, an older bundle kept aside, an equal version, or an unreadable version. Rationale: a copy with no installed sibling could be an old bundle the user wants, and the project's rock-solid priority says fail toward the Trash.

### Daemon-client reuse (takeover reasoning)
A pooled keep-alive connection is safe across the daemon takeover: the exiting old daemon drops its connections (see the `answersAfterDrop` note in `internal/daemon/client.go`), and the transport then dials the socket's new owner. A stale answer can only report the old version, which delays health but can never fake it. No unit test; checked structurally with the plan's awk gate.
