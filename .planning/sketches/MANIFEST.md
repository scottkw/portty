# Sketch Manifest

## Design Direction
Portty looks plain. The user picked every mood offered (calm native, pro tool, warm & friendly, remote-first), so round 1 compares three looks. Each one shows remote status prominently: a dot or badge per Mac, a host label on remote tabs, and a visible reconnecting state. Limits: macOS-native (system font, accent, light/dark, vibrant source-list sidebar), radical simplicity (no new features, no theme library).
