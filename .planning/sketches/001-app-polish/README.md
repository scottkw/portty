# 001: App polish

**Question:** Which overall look should Portty take?

**Variants:** A Calm native, B Pro tool, C Warm & friendly. Use the toolbar to switch between Connected and Reconnecting and between light and dark.

**Winner:** keep the current design (A is close to it) and add four upgrades: accent-colored sidebar icons, an amber status dot while reconnecting, a host label on remote tabs, and one color per Mac shown as small dots (from C).
