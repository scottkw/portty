## Flagged decisions and assumptions

- **URL shape (CONTEXT; reversibility one-way, settled by the user in 14-CONTEXT, so no new checkpoint).** No `start_url` and no `id`: WebKit defaults `start_url` to the document URL and `id` to `start_url` (RESEARCH Pattern 6, WebKit parser). Either field would pin a path or a token. `scope: "./"` resolves against `/app/manifest.json` to `/app/`, which contains the launch URL. If 14-07's early spike, 14-13 or the real phone shows the query is dropped, the checkpoint there routes to re-discussion; this plan does not hedge with a second design.
- **CSP (CONTEXT; reversibility costly).** Insert `manifest-src 'self'; ` after `worker-src 'self'; ` in cspHeaders. Chromium blocks the manifest under `default-src 'none'` (reproduced, RESEARCH Q2); WebKit checks manifests against CSP (source read). Icons stay under `img-src 'self'`. Add an "Amendment 4 (Phase 14, MOB-02, 2026-11-22)" block to the package doc in the style of Amendments 1-3: the full policy, the rationale, that the manifest is a static same-origin file with no start_url and WebKit rejects a cross-origin start_url or scope, and that 14-SECURITY-REVIEW.md carries the sign-off. Update every existing test that pins the full policy string.
- **Head tags (UI-SPEC, Home Screen).** Values exactly as UI-SPEC's table. The Wails app shares index.html; its meta CSP names only frame-src, child-src and worker-src, so it does not restrict manifest-src, and WKWebView does not fetch a manifest unless asked (A10, checked on the VM in 14-12 row P-06). Leave the meta CSP and the inline splash style untouched.
- **Relative URLs.** The SPA is mounted at `/app/` with Vite `base: './'`. After `pnpm --dir frontend exec vite build`, `frontend/dist/index.html` must reference `./manifest.json` and `./apple-touch-icon.png` (relative). Write the source hrefs in whichever form Vite turns into those (public-dir files are usually written root-absolute in the source and rewritten under a relative base); check the built file.
- **Icon recipe (UI-SPEC, Icon; RESEARCH Code Examples).** `build/appicon.png` is a 1024 px macOS squircle with a shadow and transparent margins. Build a 1024 px opaque square with the tile's vertical gradient (about `#3067FF` top to `#204EE6` bottom), composite the white "p" and dark underscore glyph cut from the source tile scaled for the larger tile and centred inside the central 60%, `-alpha off`, sRGB; save as `build/appicon-fullbleed.png`; export 180 (`frontend/public/apple-touch-icon.png`), 192 (`icon-192.png`) and 512 (`icon-512.png`) with `magick` or `sips`. Run the tools ad hoc; never write their install path into a tracked file (tests/check-brand.sh flags the macOS package manager's name). Look at the 1024 source once (Read the PNG) before exporting.
- **Playwright.** `frontend/e2e/global-setup.ts` rebuilds the bundle only when `frontend/src` is newer than `dist`; changes in `public/` and `index.html` need `PHASE_93_FIXTURE_REBUILD=1`.
- **Executor constraints (every Phase 14 plan carries these):**
  - Every Go command runs with `export GOTOOLCHAIN=go1.26.11`. Confirm 14-01-SUMMARY.md exists first; if not, stop.
  - Never run anything on the host that talks to the host's live tailscaled or a 100.x address.
  - Logs live in a private `mktemp -d` directory, printed by the verify and recorded in the SUMMARY. Never pipe a test run through `tail` or `head`. Run targeted Go packages here (the full Go suite runs in 14-03 of this wave and in 14-12's full gate).
  - Stage files by explicit path only. Never stage `.gitignore`, `.planning/state.json`, `.ignore` or `agenthub/`. Plain `git commit`, ending with the commit attribution in effect at execution time.
  - No new npm package. TESTING.md is updated by 14-12 and 14-14.
