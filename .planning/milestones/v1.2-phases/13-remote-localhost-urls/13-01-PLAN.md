## Flagged decisions and assumptions

- **Boundary rules (RESEARCH Finding 5, adopted as written).** Needles: `http://` + host + `:` + the decimal port (`strconv.Itoa`, no leading zero), host one of `localhost`, `127.0.0.1`, `[::1]`, `0.0.0.0`, `[::]` (CONTEXT "Scope and failures"). Before the needle: start of line, whitespace, or one of `( [ { < " ' , = ;`. After the needle: end of line; whitespace; one of `/ ? # ) ] } > " ' , ;`; or `.` followed by end of line or a non-alphanumeric character. Anything else after it (digit, letter, `@`, `:`, `-`, `_`, `%`, `~`, `+`) refuses, so `:80` never matches inside `:8000` and `localhost:8000@evil` never matches. Case-sensitive: printed text must be canonical lower case.
- **The search is the Phase 12 search.** `pathSnapshot` (history plus live screen, ANSI stripped, soft-wrap marks, the alt-screen seam) and both passes (`firstPass` joins wrap-marked rows; `fallbackPass` joins by fullness) are reused through a predicate. `fallbackPass` bounds its run by the needle length; for URLs that bound is the longest needle for the port (`http://127.0.0.1:` plus the port's digits). Path clicks keep calling `hasToken` with `len(text)`: behaviour unchanged, pinned by the untouched pathclick_test.go.
- **Busy guard.** `portPrintedBusy atomic.Bool` beside `pathClickBusy` (hub.go:101-103): a second concurrent search answers false, the same as "not printed". A write-cap holder cannot stall `emuMu` with back-to-back 10,000-line snapshots (RESEARCH Security Domain, DoS row).
- **No log line in the hub.** The share server logs the grant outcome (13-03) with the session id8 and port only.
- **Token design (RESEARCH "Token design", CONTEXT "Post-research refinements").** `PortClaims{SID, Port, IAT, GrantID, Kind, V}` with JSON tags `sid`, `port`, `iat`, `grant_id`, `kind`, `v` in that declaration order (the HMAC signs the marshalled bytes, as in capability.go). `PortKey(sessionKey) = hkdf.Key(sha256.New, sessionKey, nil, "portty/port-token/v1", 32)`. `SignPort`/`VerifyPort` copy Sign/Verify's mechanics under `PortKey`; `VerifyPort` also requires `Kind == "port"` and `V == 1` (new `ErrWrongKind`). No expiry claim: lifetime is the grant and the key (CONTEXT: stopping the share kills it; regenerating the key kills it).
- **Reversibility.** The token format is part of the cross-Mac contract tied to API 5 (CONTEXT "Security contract": one-way, human-settled; HKDF derivation from "Post-research refinements"). No new checkpoint.
- **Size (advisory).** `estimate-calibration`: factor 1, 0 samples, confidence low, so `tokens` equals `raw_tokens`.
