## Flagged decisions and assumptions

- **Decision tree (RESEARCH "PDF spike decision tree", CONTEXT "PDF in Safari"):**
  - (a) A variant renders in Wails and in Safari under some candidate directive: ship that variant with that directive. Prefer iframe, then object, then embed, and the candidate that adds the fewest directives.
  - (b) A variant renders in Wails, and Safari renders none under any candidate without loosening `frame-ancestors`: browser viewers get an Open PDF button that opens the PDF blob top-level; the share CSP delta is `blob:` in img-src only (no frame-src or object-src, since browsers then show no inline PDF). Record whether the top-level open itself works.
  - (c) No variant renders in Wails: write the evidence, commit it, and stop with a checkpoint that lists the options (pdf.js needs the user's sign-off, a worker and a bigger CSP delta; anything that writes the remote file to disk violates CONTEXT). Do not run Task 2.
  - `frame-ancestors 'none'` is never loosened or removed, in any candidate.
- **Throwaway spike patch, never committed.** Create a detached worktree outside the repo checkout: `git worktree add --detach /tmp/p11-spike HEAD`. All spike edits and builds happen there; it is removed with `git worktree remove --force /tmp/p11-spike` and `git worktree prune` at the end. The patch (Claude's discretion on details):
  - a spike page component in the spike worktree's `frontend/src/` that `frontend/src/main.tsx` renders instead of App (both the Wails window and the share page `/app/` then show it);
  - a 3-page text fixture PDF made on the host (for example `cupsfilter` of a text file) and an SVG fixture (a coloured shape with text, plus a `<script>`, an `onload` handler and an external `<image href>` pointing at `http://127.0.0.1:8765/svg-beacon`), both embedded in the bundle as base64 string constants and turned into Blobs (`application/pdf`, `image/svg+xml`) with `URL.createObjectURL`, so no fetch is involved and connect-src plays no part;
  - four sections: `<iframe src=blob:>`, `<object data=blob: type=application/pdf>`, `<embed src=blob: type=application/pdf>`, and `<img src=blob:svg>`, each with load and error listeners, a document-level `securitypolicyviolation` listener, and a visible `<pre id="spike-log">` plus `document.title` summarising the results (AX dumps read the title and text); buttons to show one variant at a time if the stacked view is ambiguous; an Open PDF button calling `window.open` on the PDF blob URL with `noopener`;
  - in the spike worktree's `internal/webserver/csp_mw.go` only: img-src becomes `'self' data: blob:`, and the trimmed contents of `/tmp/p11-spike-csp` (re-read on every request; an absent file adds nothing) are appended as extra directives before `frame-ancestors 'none'`, which stays last and unchanged.
