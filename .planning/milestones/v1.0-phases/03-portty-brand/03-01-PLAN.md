## Phase Goal

Everything a user sees or types says Portty: app, CLI, paths, icons, docs, notifications, and update feed. (ROADMAP Phase 3 goal, verbatim.)

This is the first of six sequential plans. It does the one change everything else builds on: the Go module path rename, which must land as one atomic, green commit. With it come the three on-disk path builders, the CLI text, and the background service name. Plans run on the main tree in order (03-01 → 03-06) on branch gsd/phase-03-portty-brand, so the build and all tests must pass at the end of every task.
