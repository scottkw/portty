## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan removes agent-CLI detection and shell discovery (STRP-01) and pins the login shell to one resolver so what the user sees is what spawns (TERM-01).

<objective>
Collapse shell resolution to one darwin resolver shared by display and spawn, then delete CLI detection, PATH discovery for agents and shell discovery from the daemon, the GUI bindings, App.tsx and the Settings Paths table.

Purpose: STRP-01 detection half; RESEARCH Pattern 3 ("one shell resolver used by both spawn and display").
Output: resolveDefaultShellPath ($SHELL check → /bin/zsh), no internal/pty detect/shells files, no DetectCLIs/ListShells anywhere, Paths table per UI-SPEC.
</objective>
