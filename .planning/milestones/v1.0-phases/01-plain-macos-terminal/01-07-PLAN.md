## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan removes agent identity from every UI surface (STRP-01) and keeps the one-time raw-shell web-share warning working now that every session is a shell. Plan 01-08 then removes the field from the daemon, webserver, peer and CLI wire.

<objective>
Make the frontend stop reading or showing the session agent/CLI field: tabs, Hub cards, Hub modal, Hub search, remote adapters and the web-share warning gate; delete agent badges, their palettes and agent help sentences; rename the warning's secondary button.

Purpose: CONTEXT "Remove the agent/CLI field from the session API ..." and UI-SPEC section 3. Ordered before the Go wire removal (plan 01-08) on purpose: if Go stopped sending cli first, Hub search would throw on an undefined field and the web-share warning gate would silently never fire between plans.
Scope note (checker scope_sanity): of the 26 listed files plus about 15 unlisted test files whose SessionInfo/Tab mocks set cli, those ~15 mock files each lose a one-line cli key (mechanical, found by tsc --noEmit); 12 listed test files get assertion updates that follow the source change; App.d.ts, the dead-tree models.ts, remoteSession.ts, remoteAdapter.ts, HubModal.tsx and HubPanel.tsx are 1-3 line deletions; substantive source edits are App.tsx, TabBar.tsx, SessionCard.tsx, SessionShareModal.tsx, ShellWebShareBanner.tsx, style.css and getting-started.md.
Output: frontend with no agent identity, UI-SPEC warning copy, updated tests and TESTING.md.
</objective>
