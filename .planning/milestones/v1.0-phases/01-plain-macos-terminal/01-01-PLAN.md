## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim. It is not in user-story form; no story is invented here.)

This plan delivers the Windows/Linux slice of that goal (STRP-03) and keeps the regression suite honest on macOS (STRP-04).

<objective>
Remove every Windows and Linux code path, packaging artifact, installer and CI job, and make macOS the only build/test target, while keeping the ubuntu-hosted Playwright e2e job compilable.

Purpose: shrinks the tree before the feature removals, and makes every later plan verifiable on this Mac with a traceability check that really checks something (Pitfall 2 in RESEARCH.md).
Output: macOS-only Go tree, macOS-only CI/packaging, portable traceability script, untracked build binaries, updated Welcome tab / README / TESTING.md.
</objective>
