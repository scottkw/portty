## Phase Goal

The app is a plain macOS terminal: new sessions run macOS zsh (`/bin/zsh -l`), no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim. It is not in user-story form and no story is invented here.)

This plan delivers ROADMAP success criterion 6 (TERM-05) and the automated half of criterion 2 (TERM-02), per CONTEXT Amendment 2 ("No status or exit UI, no bell notifications"). The awaiting-input notification toggle (also Amendment 2) is removed in plan 01-11 with the other Settings plumbing, because it shares those files.

<objective>
Replace the per-session exit poll (which stops after 5 minutes and only runs for sessions created in this GUI run) with one app-wide exit watcher. Every shell exit closes its tab right away and removes the session. Delete every exit and status surface: exit toast, countdown banner, Keep Open, auto-close toggle, tab status dot, Hub status and attention UI, briefing modal, and quit-dialog status.

Purpose: CONTEXT Amendment 2 ("when a session's shell exits, for any reason or exit code, its tab closes immediately and the session is removed. Exit detection must still be reliable for long-lived shells"), RESEARCH Pitfall 12 (the 300 s poll window), REQUIREMENTS TERM-05 and TERM-02.
Output: app-wide exit watcher plus tests, App.tsx close-on-exit and restore filtering, and deletion of the exit/status UI, auto-close plumbing, hubStatus and HubBriefingModal.
</objective>
