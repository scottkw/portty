## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan delivers the headline capability (TERM-01): every new session, from the GUI or the CLI, is the user's login shell. It also removes the per-agent spawn behavior (STRP-01 part) and keeps theming intact (TERM-04).

<objective>
Make session creation shell-only end to end: daemon API, engine spawn ($SHELL resolver + -l), client, Wails binding, GUI New Session modal (UI-SPEC section 1) and the `new [dir]` CLI. Remove per-agent spawn behavior (status watcher hook, OpenCode env/config, OpenCode SIGUSR2 theme broadcast).

Purpose: TERM-01 plus the creation half of STRP-01. Shells launch with -l because go-pty discards Args[0], so the argv0 "-zsh" trick is impossible (RESEARCH summary point 4).
Output: new CreateSession contract everywhere, test seam for deterministic tests, UI-SPEC modal, no OpenCode code.
</objective>
