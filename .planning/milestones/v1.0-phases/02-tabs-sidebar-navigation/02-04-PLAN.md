## Phase Goal

Users navigate everything from tabs plus a sidebar: the Hub grid is gone, and the sidebar lists local sessions and tailnet peers' sessions, each opening in a tab. (ROADMAP Goal, verbatim.)

This plan delivers ROADMAP success criteria 1-3 (NAV-01, NAV-02, NAV-03). GUI remote attach moves from the Hub remote cards to sidebar peer rows before the Hub files are deleted in plan 02-05, so remote attach never regresses (Roadmap decision). After this plan the Hub, Welcome and Help components are orphaned (nothing renders them); plan 02-05 deletes the files.

<objective>
Rebuild the sidebar as a macOS source list. A "This Mac" group comes from an always-on session poll, then one group per tailnet peer with shared sessions, then a Tailscale footer. Clicking a row focuses or opens its tab. App.tsx stops rendering the Hub, Welcome and Help tabs and launches straight into sidebar plus tabs. Add Hide/Show Sidebar and the inactive-window selection colour.

Purpose: CONTEXT ▸ Sidebar & Tabs ("This Mac" group, peer groups, Tailscale footer, no Home/Hub/Help/Settings/custom-group items; clicking focuses or opens; peer click attaches; Tailscale-off muted line; app launches straight into sidebar + tabs) and CONTEXT ▸ Light/Dark, Chat & Cuts (custom session groups POL-05 cut). UI-SPEC "Sidebar", "Peer group states", "Interaction Contract".
Output: a rewritten Sidebar.tsx, sidebarPeers.ts with tests, an App.tsx restructure, tab-bar inset support, updated tests and e2e, and TESTING.md.
</objective>
