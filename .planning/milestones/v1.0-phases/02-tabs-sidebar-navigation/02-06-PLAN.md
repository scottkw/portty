## Phase Goal

Users navigate everything from tabs plus a sidebar: the Hub grid is gone, and the sidebar lists local sessions and tailnet peers' sessions, each opening in a tab. (ROADMAP Goal, verbatim.)

This plan finishes ROADMAP success criterion 1 (NAV-03) on the settings and Go side. With the Hub gone, the "stay on Hub after creating a session" preference has nothing to stay on, so it is removed end to end: Settings, App, the Wails bindings, the daemon client, the API and the engine. Its settings.json key is dropped on save, following the Phase 1 legacy-key pattern.

<objective>
Delete the stay-on-Hub preference everywhere, so creating a session always activates its tab. Old settings files still load and lose the key on the next save. Remove the Hub-only GetSessionStyledTailLines binding while you are in the bindings, and reconcile TESTING.md.

Purpose: RESEARCH "Hub Removal Blast Radius" (stayOnHubAfterCreateRef row: "Delete. Always activate a new tab", with the Go deletions and the migration-test flip) and orchestrator resolved default 7 (the only settings.json key this phase drops is stayOnHubAfterCreate; themes lived in localStorage).
Output: no stay-on-Hub code, a flipped migration test, a removed-route test, the renamed sessions-seed test, and TESTING.md.
</objective>
