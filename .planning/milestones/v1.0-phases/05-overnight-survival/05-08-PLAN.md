## Flagged decisions and assumptions

- Toolchain: every Go command in this plan runs with `GOTOOLCHAIN=go1.26.11` (05-11 pins it; tailscale.com v1.98.3 JSON decoding breaks on Go 1.27, and the local Homebrew Go is 1.27.4). The toolchain is already in the module cache.
- Geometry policy (Claude's discretion, reversible): the ring stores raw PTY bytes but not resizes. Bytes written before a host resize, replayed into a guest at the new width, put Claude Code's relative redraws in the wrong rows (the jumble). So Join treats a **genuine** host geometry change (ResizeClient changes the PTY grid while the hub already had a real grid, i.e. old ptyCols and ptyRows were both > 0, and the live emulator exists) as a boundary: delta only when `resume >= geomEnd`, raw full replay only when the ring is intact and no genuine change was recorded. Otherwise the rendered path (history + screen + CUP + modes, 05-03). The hub's first resize from its unknown grid (ptyCols 0, emulator built at the 220x50 fallback) is NOT genuine: the PTY was spawned at the GUI's grid, so the bytes were already laid out for it. This keeps the #109 raw path for the common case (Chesterton: #109 raw replay is byte-faithful when geometry never changed).
- The wire contract is unchanged (Meta{replay}, chunks, Meta{offset}); only which content a full replay carries, and when a delta is refused, changes.
- Fixture content is synthetic (generated text), never captured terminal data.
- The Claude-Code-like generator is deterministic (no time, no randomness) so the fixture is stable across runs.
