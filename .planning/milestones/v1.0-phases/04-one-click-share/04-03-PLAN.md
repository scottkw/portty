## Phase Goal

Sharing is one on/off switch per session: shared means tailnet peers and a tailnet web link at once, always full control, with a clean stop and CLI attach from any terminal. Funnel and read-only links are gone. (ROADMAP Phase 4 goal, verbatim.)

This plan adds the two access rules the share switch needs on the host Mac. Peers on the same Tailscale account get the share's capability automatically; everyone else is refused. Stopping a share disconnects every viewer with a fixed reason that the peer GUI, the CLI and the browser can recognise, and a dead link shows a page instead of plain text. 04-04 consumes the peer route from the viewing Mac. Sequential plans; green at the boundary.

<objective>
Add the WhoIs same-user middleware (fail closed) on discovery and on a new peer-capability route, revoke viewers with the fixed close reason `share stopped` and close the subscribe race, end the plugin-config stream on revoke, serve a static "Link No Longer Works" page for failed link opens, and add Referrer-Policy.

Purpose: SHAR-01 (shared means visible to the user's tailnet peers), SHAR-03 (links stay token-gated; revoked links explain themselves), SHAR-04 (stop disconnects remote viewers), ROADMAP SC1 and SC3, CONTEXT ▸ Who can use a share (same tailnet user via WhoIs through tailscale.com/client/local; different user hidden with 403), Claude's discretion (test strategy for WhoIs: fake local client), UI-SPEC Web pages.
Output: whois.go and tests, relay close-reason constants, revoke and link-page tests, web/link-invalid.html, daemon wiring, TESTING.md rows.
</objective>

## Flagged decisions and assumptions

- [ASSUMED, RESEARCH A2] `Node.User` of the user's other Mac equals this Mac's `Status.Self.UserID`. If wrong, same-account peers are refused; the deferred two-Mac UAT (M-80, added in 04-06) catches it, and a debug log on refusal records both numeric IDs (no names).
- [ASSUMED, RESEARCH A1/A4] Tagged nodes and nodes shared in from another tailnet are refused outright. Strict on purpose: the user's two Macs are in one tailnet, signed in as the user.
- The link routes stay capability-only so any tailnet device with the link works (locked decision). Only discovery and peer capability issuance are WhoIs-gated.
- The "Link No Longer Works" page is a static embedded file: nothing from the request is rendered into it, so it cannot leak the host, session name or ID.
- Wording rule for everything this plan writes outside `.planning/` (TESTING.md Section 4 rows and Section 5 items, code comments, test names and strings, docs): describe removed features by concept — public internet sharing, the consent UI, code-based access, view-only links, the LAN server, the share reminder — never by the words the 04-06 removal gate (`tests/check-share-removal.sh`) checks. TESTING.md Section 2 history notes are outside the gate and may name them.
- `CloseSlow` ("too slow", policy violation) stays for genuinely slow consumers; only revocation uses the new reason.
