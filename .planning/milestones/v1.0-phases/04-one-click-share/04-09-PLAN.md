<objective>
Close UAT gaps 2 and 3.

Gap 2 (cosmetic): the browser's stop banner read `Kens-MacBook-Air.local stopped sharing this session.` while the GUI and CLI said `kens-macbook-air-1574`. The browser takes its host label from the share server's session info. Its resolver (internal/daemon/share.go startShareServer) returns the engine's OS hostname. The GUI and CLI take the first label of the peer's MagicDNS name (peerShortName in peer_connect.go; shortHost in the sidebar). The share server already knows its own MagicDNS name: the tailnet certificate domain h.Domain, which is the same FQDN. The fix is one shared helper and a resolver change. The frontend already shows whatever host the info returns.

Gap 3 (minor): with Tailscale off, the toolbar Share/Shared button is aria-disabled, so a shared session's popover (whose switch can still turn Share off) can't be opened. User decision 2026-11-17, locked: "Button opens when shared". For a shared session with Tailscale off, the button stays enabled and opens the popover; the popover shows the Tailscale-off reason and its switch can only turn Share off. For an unshared session with Tailscale off, nothing changes. The popover already handles that state (`blocked` only while not shared; the reason replaces the link). Only App's shareDisabled expression changes, plus the spec, tests and TESTING.md.

Purpose: the browser names the host like every other surface, and the popover switch can stop a share while Tailscale is off, as the spec promises.
Output: magicDNSLabel and the resolver change with tests; App shareDisabled rule with mounted tests; 04-UI-SPEC.md reconciled; TESTING.md updated.
</objective>
