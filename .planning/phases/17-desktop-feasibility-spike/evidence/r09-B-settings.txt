Spike entries in Screen Recording, Accessibility and Login Items: 1 + 1 + 1 = 3 (the tiebreaker count for the daemon shape). R09-A, the helper, also counts 3.
Plain Mach-O versus bundle: the bare Mach-O inside the app bundle is NOT listed by its own path. tccd resolves it to the enclosing bundle (BUNDLE_ATTRIBUTION: main executable for candidateBundle Spike.app), so Settings lists the bundle as Spike for both Privacy panes, and one TCC key (Bundle ID app.portty.spike) serves Screen Recording and Accessibility. The helper shape needed two keys (a bundle for Screen Recording, a path for Accessibility).
Login Items: the row is named after the signing developer, not after the app, because the legacy plist has no bundle association; a Phase 19 onboarding text that says "Spike" would not match what the user sees there. A banner named it on first load: "Software from DEVELOPER can run in the background."
