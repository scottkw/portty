## Flagged decisions and assumptions

- **Rig (CONTEXT Test rig):** VM `portty-test` is the shared Mac. No tailnet is needed for R00 or R10, so this plan does not wait for the re-key (17-07). Starting the VM is allowed; stopping it is not (ephemeral tailnet node; 17-07 re-keys it).
- **Tool copies:** `~/.local/share/portty-vm-tools/vm.sh` hard-codes an old IP and `vshot.sh` an old scratchpad. Make session-scratchpad copies (`vm-office.sh`, `vshot-office.sh`) with the IP from `tart ip portty-test`; never edit the originals. The guest has no swiftc: compile `click.swift` on the host if `~/ptest/click` is missing and copy it over with tar. `~/ptest/axdump` already lives in the guest (memory); if it is gone, build a small scratch AX-tree dumper on the host and copy it in.
- **GUI driving:** the executor drives every TCC click in the guest (click, vshot, axdump, axmenu); the guest login is admin/admin. Never hand a VM GUI step to the user.
- **Gatekeeper (RESEARCH A8):** if a Gatekeeper dialog blocks the first `open`, record its text in r00-rig.txt and stop with a `checkpoint:human-action`: notarizing the spike needs the user's notarytool credentials.
- **R00 failure is data, not a blocker:** a NO-GO re-routes rows per CONTEXT ("If VM capture fails, the affected rows move to the host run and the matrix records why"); the plan still completes.
- **Spec-less probe:** FEAS-01 concurrency edge applied here as the no-overlap truth.

## Executor constraints (every Phase 17 plan carries these)

- Spike Go commands: `GOTOOLCHAIN=local go -C spike/desktop ...`. Root Go commands: `GOTOOLCHAIN=go1.26.11`.
- Never run anything on the host that talks to the host's live tailscaled or a 100.x address (only exception: the user-gated host run in 17-11). Never open Spike.app on the host.
- Never touch `~/Downloads` or `/Applications` on the host. Never stop a Tart VM.
- Launch GUI-path probes only with `open` in the guest.
- Evidence: filter tccd logs to the probe pid; replace `/Users/<name>` with `/Users/USER`; frames at most 1280 px (sips -Z 1280 in the guest); no `.h264` in git.
- Fail loudly; stage by explicit path only; never stage the root `.gitignore`, `.planning/state.json`, `.ignore`, `agenthub` or milestone `.gitkeep` files.
