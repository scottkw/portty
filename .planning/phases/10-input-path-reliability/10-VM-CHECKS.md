It gives the share connections the same silent stall as a dead network (no RST; heartbeats and watchdogs fire), while `tailscaled` stays up and the ephemeral node stays online, so Tailscale cannot delete it. The plan's `tailscale down` fallback is not needed: R-00's pf preflight passed. R-03 and R-04 (the drops themselves) were not run in this pass. For the user to accept.
