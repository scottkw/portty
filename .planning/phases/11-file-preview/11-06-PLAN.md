Offer the toggle only when the natural size exceeds the fitted size (measured on load and on pane resize); the `<img alt="<name>">` sits inside `<button class="preview-image__toggle" aria-label="Actual Size" aria-pressed>`; at Actual Size the pane scrolls both ways from the top-left; cursor zoom-in, zoom-out, or default with no toggle. Checkerboard on the img element itself (a conic-gradient of the two new tokens, 16px tile). An SVG is never put anywhere but an `<img>` (inside an img an SVG runs no script and fetches nothing: CONTEXT "Image rendering").
- **Hostile SVG fixtures (for the tests here and 11-10's VM beacon rows):** hostile-script.svg (a visible shape, a `<script>` that changes the document title and fetches the beacon, an `onload` handler doing the same) and hostile-external.svg (an external `<image href>`, a `<use href>`, a `<foreignObject>` holding an iframe, a `<style>` with `@import`, and a billion-laughs entity block), every network reference written as `http://BEACON/<label>` so 11-10 can point it at the VM's loopback beacon.
