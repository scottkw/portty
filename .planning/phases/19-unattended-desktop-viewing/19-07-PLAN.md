## Flagged decisions and assumptions

- **Ad-hoc signing is enough here:** these rows need no TCC grant. 19-12 uses Developer ID builds for the capture rows (R10: grants survive a same-identity rebuild).
- **Two builds for V3:** N and N+1 from the same commit with patched versions, as p18-rig.sh does, so the handoff and re-home run on the real code paths.
- **Legacy agent for LG1:** written by the rig from the old kardianos shape (label portty-daemon, ProgramArguments the installed Portty with `daemon`), loaded with bootstrap, so the row does not depend on an old release binary.
- **Stop rule:** a CONTRADICTED V2 or V3 stops the phase at this plan and is reported with the alternatives (for example: a kill-free re-home through the daemon's own handoff endpoint). A GUI spawn fallback is not an alternative: CONTEXT locks launchd as the only start path.
