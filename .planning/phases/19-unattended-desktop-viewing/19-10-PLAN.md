<objective>
Carry always-available across an upgrade without changing the handoff protocol: the old daemon passes the share listener whenever `serverNeeded()` holds (desktop-only included), the new daemon builds the share server for a desktop-only handoff from desktop.json, desktop viewers are closed by the old daemon after COMMITTED and reconnect to the new one on the same link, the media port is re-bound by its new owner once released, and a v1.2-shaped old daemon is handled by the poller.

Purpose: DSHR-02's upgrade half (links survive upgrades), DESK-03's upgrade case (viewers come back by themselves), and ROADMAP SC5 (terminal sessions keep PIDs and history with the desktop on). The real two-build upgrade with a live viewer runs in the VM in 19-15.
Output: handoff.go changes and an in-process handoff test file.
</objective>

## Artifacts this phase produces (this plan)

- `internal/daemon/handoff.go`: `func (a *API) closeDesktopForHandoff()` (takes the Manager under a.mu, nils it, then CloseAll(1012, "server restarting") and Close outside the lock); `oldHandoff.global` passes the share listener when `ws != nil && a.serverNeededLocked()` (read under a.mu.RLock); `takeover.finalize` loads desktop.json (desktop.LoadConfig on the engine's config dir) into a.desktopCfg, and when there are no imported shares: always-available on with a share listener builds the server exactly like the shares case; always-available on without a listener builds nothing and returns nil; always-available off drops as today; the takeover's serve path starts runDesktopPoller if 19-08 did not already start it from a path the takeover runs.
- `internal/daemon/handoff_desktop_test.go`: tests named in the tasks.

## Flagged decisions and assumptions

- **Same listener, no new frames (research Pattern 4):** the gob already carries ShareListener and Shares; the UDP media socket is never passed (no fd frame for it and the protocol must not change), so the new owner re-binds it with listenMedia's retry (19-03).
- **Old side order:** viewers are closed with 1012 (the existing restarting-server code the viewer treats as a wake) only after COMMITTED, so a rolled-back handoff never drops desktop viewers.
- **v1.2 old side:** passes no listener when nothing is shared; the new daemon's poller starts the server after the old one exits (port_in_use until then, retried every 10 s).
