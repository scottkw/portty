## Flagged decisions and assumptions

- **iat in desktop.json (research C3, post-research decision):** written once at turn-on, so the HMAC (deterministic over the marshalled claims) gives the same link text after every restart.
- **Userspace networking (A17):** detected as "the tailnet IP from Tailscale health is not assigned to any local interface"; M-row in 19-16 confirms the office Mac's mode (the user reports the standalone app, so the network extension).
- **Malformed desktop.json is an explicit state, not a reset** (CLAUDE.md Silent Fallbacks): the desktop stays off with a Reason; the daemon keeps serving terminals.
- **Notifier seam:** `SetDesktopNotifier` stores a package var passed as Deps.Notify; 19-11 calls it from cmd_daemon.go (the daemon side of CONTEXT's 'the GUI when it runs, otherwise the daemon'); 19-14 adds the GUI side and the claim endpoint.
- **Media bind on enable uses a 5 s window** (not listenMedia's 30 s handoff window); a busy port answers port_in_use and rolls desktop.json back.
- **Production Manager deps:** NewSource screencap.NewDisplaySource and SourceConfig screencap.DefaultConfig(); 19-09 supplies its own defaults for power, lock and probe inside internal/desktop, so this file does not change when 19-09 lands.
