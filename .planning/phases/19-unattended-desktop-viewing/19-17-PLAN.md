## Flagged decisions and assumptions

- **Repair state on the existing banner:** no new component; the banner already shows the daemon error with Retry Connection, so the repair kind only adds one button. The repair sentences come from 19-02's typed errors.
- **Login Items URL:** the System Settings extension URL for Login Items on macOS 13+; 19-07 row V2(d) confirms it opens the right pane in the VM.
- **Installed bundles only (checker final revision):** a build-tree bundle or dev binary never writes the production agent (it would point every login at a build tree); VM rigs install into /Applications inside the VM, so they exercise the real path.
- **Re-home retry (checker final revision):** one kickstart at startup can be lost if the takeover daemon is still settling, so the tray tick retries with bounded backoff while health says unmanaged.
- **Open Login Items only for disabled and refused** (the missing-agent sentence already gives its fix).
