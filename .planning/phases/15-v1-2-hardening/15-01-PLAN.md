## Flagged decisions and assumptions

- **Both positions get rows-1 (CONTEXT post-research [Attach bar]).** Bottom (the default) is fully fixed: the app's rows 1..rows-1 map onto the scroll region above the bar. With `--status-top` the bar sits on row 1 and nothing enables origin mode, so an app that addresses absolute rows can still paint row 1. That is the user's accepted limit: record it in a comment at the `onConnect` call site in cmd_attach.go (the comment must contain the words `origin mode`), and 15-07 records it in TESTING.md M-153. Do not add an escape sequence to the bar (bar.go keeps exactly its 8 escape constants, UI-SPEC row 4).
- **The reserve is "the bar sized itself", not "a bar exists" (RESEARCH Pitfall 3).** `Bar.Start` returns without drawing when it cannot read the terminal size, so `ReservedRows` returns 1 only once `Start` stored a size (`b.rows > 0` under `b.mu`), else 0, and a nil `*Bar` returns 0 (cmd_attach.go leaves `bar` nil when stdout is not a TTY). The reserve is read per connection and per SIGWINCH, after `Start`.
- **watchResize gains a reserve parameter (deliberate deviation from RESEARCH Pitfall 11).** Research suggested keeping `watchResize(ctx, conn, winch, size)` unchanged and subtracting inside `WatchResize`'s closure. That leaves the subtraction untested, since `WatchResize` reads the real stdin. Instead `watchResize(ctx, conn, winch, size, reserve func() int)` applies `BarRows` itself, so a test drives the reserve through the real loop; the one existing caller in attach_test.go passes a zero reserve and keeps its expectations.
- **The initial frame stays a report, never a claim** (RESEARCH Item A): it only becomes the grid on an ownerless, never-sized hub, where rows-1 is the right size. The existing shortcut comment on `MakeClientResizeFrame` stays.
- **Uint16 wrap (RESEARCH Pitfall 2):** `BarRows` subtracts only when `reserve > 0 && rows > reserve`.
- **Deferred, not here:** a flag to turn the bar off (CONTEXT Deferred Ideas).
- **Reversibility:** reversible (two call sites and one pure helper; a local revert undoes it).
