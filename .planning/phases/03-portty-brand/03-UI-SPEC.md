# Phase 03 — UI Design Contract

> Visual and interaction contract for Phase 3 (Portty Brand: BRND-01..06, NOTF-01, DIST-03). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase renames things. It does not redesign anything. Phase 2's design contract (`02-UI-SPEC.md`, approved 2026-11-15) is locked. This contract reuses its tokens, type scale, spacing, components and copy rules unchanged. It adds four things:
1. Where each Portty brand asset goes.
2. Where the name "Portty" appears, and the exact strings.
3. The native About panel (Phase 2 deferred About to this phase).
4. How the update check behaves when no release exists yet.

**Sources, in priority order:**
1. `03-CONTEXT.md` decisions (locked; the user accepted all of them).
2. `02-UI-SPEC.md` (locked tokens, type, spacing, copy tone, menu structure, removed UI).
3. `portty-brand/README.md` (brand name, mark, colors, wordmark, asset list).
4. Existing code, scanned 2026-11-16: `main.go` (menu, window title), `app.go` (quit notification, update check), `tray_common.go`, `tray_objc_darwin.m`, `tray.go`, `wails.json`, `build/darwin/Info.plist`, `internal/daemon/service.go`, `cmd_cli.go`, `frontend/index.html`, `frontend/src/components/QuitConfirmModal.tsx`, `UpdateBanner.tsx`, `web/{dashboard,join,terminal}.html`.

## Color

No new color tokens. **The brand blue `#2457F5`, its gradient (`#3165FF`→`#1E4DE6`), ink `#0B1436`, light `#EEF1FB` and dark-mode cursor `#6F93FF` exist only inside the raster brand assets** (app icon, iconset, title logos). They never appear as CSS custom properties, hex values in `style.css` or `web/assets/*.css`, inline styles, or Objective-C `NSColor` values. The app accent stays macOS blue (`--color-accent` / `--color-selection-fill`). Phase 2's LOOK-01 source gate (no hex outside the two token blocks) must keep passing.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-window` / `--color-terminal-bg` (`#FFFFFF` · `#1E1E1E`/`#1C1C1E`) | unchanged |
| Secondary (30%) | `--color-sidebar` + `--color-toolbar` | unchanged |
| Accent (10%) | `--color-selection-fill` / `--color-accent` (`#0063CC` · `#0058D0`/`#4DA3FF`), macOS blue | unchanged |

Accent reserved for: exactly Phase 2's list (selected sidebar row fill, Shared state of the Share button, the primary dialog button, switch track when on, selected Settings pane tab, highlighted menu item, focus ring, text links, OSC 9;4 underline). In this phase the accent appears in two places, both already on that list:
- the primary "Quit All" button in the Quit dialog (the primary dialog button);

Brand color is not accent. Do not tint the toolbar, the empty state, the sidebar or the web pages with `#2457F5`.

## Component Contracts

### About panel (new; BRND-01, BRND-06)

Shown from App menu ▸ **About Portty**. It is the **native AppKit standard About panel**, not an HTML dialog. Call `[NSApp orderFrontStandardAboutPanelWithOptions:]` from the existing cgo Objective-C file, through a Go wrapper the menu callback calls. Wails v2's `mac.AboutInfo` can't be used, because the custom first submenu replaced the AppMenu role (02-UI-SPEC deviation, 02-01).

| Part | Value |
|------|-------|
| Icon | The bundle app icon (`iconfile.icns`). Pass no override |
| Application name | `Portty` (from `CFBundleName`) |
| Version line | `Version <CFBundleShortVersionString>`. Pass `NSAboutPanelOptionVersion: @""` so AppKit omits the duplicate parenthetical build number ("Version 2.2.0", not "Version 2.2.0 (2.2.0)") |
| Credits | `NSAboutPanelOptionCredits`: an `NSAttributedString` of two centered lines. Line 1: `A macOS terminal with remote access over Tailscale.` Line 2: `portty.app`, with `NSLinkAttributeName` = `https://portty.app`. Font: `[NSFont systemFontOfSize:[NSFont smallSystemFontSize]]` (11pt, regular). Line 1 color: `NSColor.secondaryLabelColor`. The link is drawn in `NSColor.linkColor` by AppKit. Both follow Light/Dark automatically |
| Copyright | `Copyright © 2026 Ken Scott. MIT License.` (from `NSHumanReadableCopyright`) |
| Behavior | Non-modal panel with a native close button. A second "About Portty" brings the same panel forward (AppKit default). Clicking the link opens the default browser |
| Not included | No GitHub link, no AgentHub credit, no license text block, no "Check for Updates" button |

If the standard panel can't be reached from cgo (unlikely: the tray code already calls AppKit), stop and report it. Don't fall back to an HTML dialog, which would break the native-look rule (LOOK-01).

### Update check (NOTF-01 boundary; full flow is Phase 6)

| Condition | What the user sees |
|-----------|--------------------|
| A newer release exists on `scottkw/portty` | The existing info banner (Phase 2 banner style, unchanged): **Update available: <current> → <latest>** + action **Download Update**, which opens the release page on `github.com/scottkw/portty`. Dismiss "×" with `aria-label="Dismiss"`. No new native notification in this phase (that's UPD-01, Phase 6) |
| No release published yet, API 404 (private repo), draft or prerelease only, network failure, rate limit | **Nothing.** No banner, no notification, no dialog, no inline error, no error text in the UI. The check is treated as "up to date". Periodic checks keep running on their existing schedule |
| Help ▸ Check for Updates, nothing newer | **Nothing visible in this phase.** The check runs; if no newer release exists, no UI appears. The explicit reply ("Portty is up to date" / "Version X is available" / a readable error) belongs to UPD-02 in Phase 6. Copy reserved for it: **Portty is up to date.** / **You're running version <current>.** |
| Help ▸ Check for Updates, newer release exists | The same banner as above |

The updater's cache lives under `~/Library/Application Support/portty/`. Nothing is read from `~/Library/Application Support/agenthub/`.

### Web pages (`web/*.html`)

Only text changes: no layout, CSS or token changes. They keep Phase 2's light/dark tokens. The `h1` becomes the text **Portty**. Copy changes are in the Copywriting Contract. Phase 4 may cut or rework the join and dashboard flow; this phase only renames.
