## Flagged decisions and assumptions

- Marker name and value are Claude's discretion (CONTEXT): `X-Portty: 1`, defined once as tailnet.MarkerHeader / tailnet.MarkerValue and imported by webserver.
- The marker is not an authentication signal. Any tailnet host could forge it; that grants nothing, because attaching still needs a capability minted by that peer (RESEARCH Security Domain).
- The DMG filter is included now (CONTEXT Research follow-ups, orchestrator default) so the UI-SPEC "newer release → banner" row is reachable. Downloading or verifying the DMG stays in Phase 6 (UPD-03).
- The CLI `web start` command still binds 443; CONTEXT leaves it for Phase 4.
