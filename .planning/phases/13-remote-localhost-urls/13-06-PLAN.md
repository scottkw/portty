## Flagged decisions and assumptions

- **How streams end (RESEARCH Pattern 2, Pitfall 7).** The host's proxied request context is cancelled by `revokeSignal(id)` (closed by `ClearGrants`, which share-off, session exit and the key regeneration's re-mint all call) and by `stopCh` (closed by `Stop`, which shutdown and a handoff call without ClearGrants); `httputil.ReverseProxy` then closes the upstream and the hijacked connection, which ends the viewing hop's copy too. If a test shows a stream outliving any of these, fix the cancellation in portproxy.go (or the forward in portforward.go), not the test.
- **Revocation without a request (13-02, checker B1).** On the viewing Mac a share-off reaches the forwards through the peer tab's session stream: the host closes it with 1000 `share stopped` (or `session ended`), `handleRemoteSessionWS` sees `relay.IsTerminalClose` and calls `RevokeSession`, which closes the forward and drops its approvals. A changed capability at reconnect (`handlePeerConnect`) does the same, and `handlePortOpen` answers open only with a live approval. Tests here must not send a request to the forward between the trigger and the assertion; the request-time stopped page is tested on its own, with no session stream open.
- **Bounds.** "Within 2 s" for a stream to end after the trigger; goroutines back to the pre-test count (tolerance of the test package's background goroutines, measured before the stream opened) within 5 s. Generous for the race detector; the research measured about 1 ms.
- **WebSocket fixture.** The dev server accepts with `github.com/coder/websocket` defaults (its same-origin check compares the Origin's host to the request Host), so a passing echo proves the Host and Origin the host sends are consistent: the client dials the forward with Origin `http://127.0.0.1:<N>`, which the host rewrites to `http://localhost:<N>` to match Host `localhost:<N>`.
- **Security review layout (12-SECURITY-REVIEW.md is the template).** Sections, in order: `## Scope and parts` (13-06 writes parts 1; 13-07 appends `## VM evidence and verdict`); `## What Phase 13 adds at the boundary`; `## Refinements of CONTEXT decisions` (each with what CONTEXT said, what was built and why: the viewing listener binds `127.0.0.1` and `[::1]`, both loopbacks, so a `localhost` request that resolves to `::1` can never reach another program (13-CONTEXT now records this, updated after 5ffe4fa8; RESEARCH Finding 1); the host rewrites Origin only from exactly `http://127.0.0.1:<P>` to `http://localhost:<P>`, never on all upgrades, so a cross-site page's WebSocket keeps its own Origin for the dev server's check (13-03); the forward refuses cross-site requests that are not navigations (13-02); approvals and forwards end on the session stream's terminal close or a changed capability with no request needed, and open is answered only with a live approval (13-02, checker B1));
