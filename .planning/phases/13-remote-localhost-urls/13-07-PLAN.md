## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| executor → host | the gate, builds, the helper build and SSH only; no daemon, GUI, dotfile or `/usr/local/bin` change on the host |
| executor → VMs | installs, upgrades, clicks, key events, curl probes and helper servers inside disposable VMs |
| VMs → tailnet | ephemeral tailnet nodes the executor cannot re-enroll |
| evidence and review → repository | log excerpts and probe results from live shares are committed |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-36 | Tampering | host machine | high | mitigate | Every GUI, daemon and app action runs only in the VMs; host commands are the gate, builds, the helper build and SSH; ad-hoc signing only; the user's own Portty and dotfiles are never touched |
| T-13-37 | Information disclosure | 13-VM-CHECKS.md, 13-SECURITY-REVIEW.md | high | mitigate | Links, capabilities and port tokens travel in 0600 files inside deleted `mktemp -d` directories, curl reads headers from files; evidence records codes, header names and hashes only; Tasks 2 and 4 grep both files for link, token and tailnet patterns |
| T-13-38 | Denial of service | ephemeral VM tailnet nodes | high | mitigate | No network drop; never stop or reboot the VMs, never `tailscale down`/`logout`, never an auth key; stop on any re-auth prompt (RULE 0) |
