## Phase 13 interface contract (identical in 13-02, 13-03, 13-04, 13-05)

**Host share server** (13-03) and **viewing daemon** (13-02, `POST /peers/ports` on the unix socket): see 13-02-PLAN.md. This plan only needs the binding below.

**App binding** (13-04 writes the Go side; this plan writes the hand-maintained TypeScript stub):
- `OpenRemotePort(sessionID: string, rawURL: string, consent: boolean): Promise<RemotePortResult>`.
- `interface RemotePortResult { status: string; url: string; host: string; port: number; errorCode: string }`.
- `status` is `'open'` (url is `http://localhost:<port><rest>`), `'consent'` (host and port set; nothing bound), or `''` with a non-empty `errorCode`.
- `errorCode` values: `bad_url`, `no_cap`, `refused`, `host_outdated`, `port_in_use`, `unreachable`, `daemon_outdated`.
- Never rejects by contract; the frontend still treats a rejection as `unreachable`.

**Classifier** (TypeScript `classifyLoopbackUrl` here, Go `classifyLoopbackURL` in 13-02, both pinned by frontend/src/lib/__tests__/fixtures/localhost-url.json):
1. Trim trailing characters while the last one is one of `] } > , ; . ' "`, or is `)` while the string holds fewer `(` than `)`.
2. Match `http://` + host + `:` + port + rest, host exactly one of `localhost`, `127.0.0.1`, `[::1]`, `0.0.0.0`, `[::]` (lower case, no folding); port 1 to 5 digits, no leading zero, 1..65535; rest empty or starting with `/`, `?` or `#`, and holding no whitespace or control character.
3. Result `{ port, rest }`, or `null` when there is no match.

## Flagged decisions and assumptions

- **Branch placement (RESEARCH "Pattern Assignments" TerminalPanel; URL-03).** Inside the existing `WebLinksAddon` handler, after `isAllowedScheme(uri)` and the `isModifierPressed` gate and before `getRisk`: when the panel is a desktop peer tab (`remote` true and no `wsURL`, read through a ref kept current like `webLinksConfigRef`) and `classifyLoopbackUrl(uri)` is not null, call the remote-port flow and return. Otherwise the handler continues exactly as today. No new link provider is registered (the Plan B test pins `lib/pathLinks.ts` as the only non-test provider), and `remote` is not added to the hot-swap effect's dependency array (a source-gate test reads it).
- **Flow.** `OpenRemotePort(sessionId, trimmedUrl, false)` where trimmedUrl is the input with the classifier's trim applied; `open` → `openLink(result.url)`; `consent` → the sheet; any errorCode or rejection → the notice. One flow per pane at a time (a ref guard): a click while one is in flight does nothing. The raw clicked text is never opened by this branch.
- **Consent sheet (CONTEXT "Consent").** `RegenerateKeyModal` with copy overrides: `title` `Allow access to {host}'s localhost:{port}?` (host from the binding's answer, else the pane's `hostLabel`), `body` `Pages from this port open in your browser through Portty over your tailnet. Other ports stay closed.`, `confirmLabel` `Allow`, `cancelLabel` `Don't Allow`, `actingLabel` `Opening…`, a distinct `titleId`, not destructive. Rendered through `createPortal` into `document.body` so a transformed ancestor (the scaled guest terminal) can never clip it. `useDialogFocus` (inside the modal) focuses Cancel first and maps Esc to Cancel. `onConfirm` calls the binding with consent true, then closes the sheet and opens the URL or shows the notice; it never throws. `onCancel` closes the sheet and calls nothing.
- **Notice (Phase 12 notice pattern; CONTEXT "Scope and failures").** A sibling of `pathNotice`: `portNotice` state `{ kind, port }` with its own timer of `PATH_NOTICE_MS`, cleared by the same conditions (pane inactive, another banner taking the slot), and showing one notice clears the other. Rendered in the path notice's slot as `SessionEndedBanner` with `kind`, `host={hostLabel}` and `port`. Code to kind: `host_outdated` → `port-host-outdated`; `daemon_outdated` → `port-daemon-outdated`; `port_in_use` → `port-in-use`; `refused` → `port-refused`; `unreachable`, `no_cap`, `bad_url`, a rejection and any other code → `port-unreachable`.
- **Copy (SessionEndedBanner; fixed text, host label and numeric port only).** `port-host-outdated`: `{host} needs a Portty update to open its local pages.` (host fallback `The host Mac`). `port-daemon-outdated`: `Portty's background service on this Mac is too old to open remote pages. Relaunch Portty to update it.` (mirrors the existing Update needed banner). `port-in-use`: `Port {port} is in use on this Mac.` `port-refused`: `{host} refused access to port {port}.` (fallback `The host Mac`). `port-unreachable`: `Couldn't reach {host}.` (fallback `the host Mac`). Each has the Dismiss button.
