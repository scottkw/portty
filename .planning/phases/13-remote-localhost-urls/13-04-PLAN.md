## Phase 13 interface contract (identical in 13-02, 13-03, 13-04, 13-05)

**Host share server** (13-03): grant `POST /api/peer/sessions/{id}/ports` and proxy `/api/peer/sessions/{id}/ports/{port}` with `X-Portty-Cap`, `X-Portty-Port-Token`, `X-Portty-Target`; refusals 403 with `X-Portty: 1`, identical; an old host answers the grant POST with 405 and no marker.

**Viewing daemon** (unix socket only; 13-02):
- `POST /peers/ports`, body `PortOpenRequest{SessionID "sessionId", URL "url", Consent "consent"}`.
- 200 `PortOpenResponse{Status "status", URL "url,omitempty", Host "host", Port "port"}`; Status `PortStatusOpen` (`open`, URL `http://localhost:<P><rest>`) or `PortStatusConsent` (`consent`, nothing bound); Host is the MagicDNS short label of the Mac the daemon will contact.
- Errors: `PortOpenErrorResponse{Error "error"}` with `PortErrBadURL` `bad_url` (400), `PortErrNoCap` `no_cap` (404), `PortErrRefused` `refused` (403), `PortErrHostOutdated` `host_outdated` (409), `PortErrPortInUse` `port_in_use` (409), `PortErrUnreachable` `unreachable` (502). `PortErrDaemonOutdated` `daemon_outdated` is defined in internal/daemon/portforward_api.go for this plan's client and binding; the route never sends it.

**App binding** (this plan in Go; 13-05 writes the TypeScript stub):
- `func (a *App) OpenRemotePort(sessionID, rawURL string, consent bool) RemotePortResult`.
- `type RemotePortResult struct { Status string json:"status"; URL string json:"url"; Host string json:"host"; Port int json:"port"; ErrorCode string json:"errorCode" }`.
- Never throws. The frontend opens `URL` with the existing `openLink` only when `Status` is `open`, shows the consent sheet when it is `consent`, and shows a notice for any `ErrorCode`.

**Classifier**: frontend/src/lib/__tests__/fixtures/localhost-url.json pins the Go (13-02) and TypeScript (13-05) classifiers.

## Flagged decisions and assumptions

- **Binding order.** `a.client == nil` gives unreachable; `a.client.HealthInfo()` failing gives unreachable; `daemon.DaemonAPI(h) < daemon.PortProxyAPI` gives daemon_outdated without calling the route (an API 4 daemon kept running after an upgrade has no forward code, CONTEXT "Decided autonomously"); then `a.client.OpenRemotePort`; a `*daemon.PortOpenError` gives its code; any other error gives unreachable. Mirrors `ConnectPeerSession` (repo-root app.go:1461-1474).
- **Client mapping.** POST JSON to `/peers/ports`; status 200 decodes `PortOpenResponse`; status 400 or above with a JSON body holding a non-empty `error` gives `&PortOpenError{Code: e.Error}`; 404 or 405 without one (an older daemon's mux) gives `&PortOpenError{Code: PortErrDaemonOutdated}`; anything else is a plain error naming the status (the binding reports unreachable).
- **Versions (RESEARCH "Daemon API shape").** `APIVersion` goes from 4 to 5 with the doc comment extended ("5 adds remote localhost forwards (PortProxyAPI)"). `PortProxyAPI = 5` with a doc comment: the lowest daemon API that serves POST /peers/ports; the GUI checks its own daemon with it; a viewing daemon learns whether a host supports forwards from the grant route's answer (405 without the marker), not from this number. `MinDaemonAPI` stays 1 (an API 4 daemon is still usable for everything else; only this click says update needed).
- **Copy is the frontend's.** The binding returns codes only; 13-05 owns the notice text, including "Portty's background service on this Mac is too old to open remote pages. Relaunch Portty to update it." for daemon_outdated.
- **Size (advisory).** `estimate-calibration`: factor 1, 0 samples, confidence low.
