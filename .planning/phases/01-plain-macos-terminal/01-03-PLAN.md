## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan removes the file browser's daemon API and capability (the server half of STRP-02) after plan 01-02 removed every UI entry point.

<objective>
Delete internal/files, every files route on the three HTTP surfaces, the files capability perms, the per-session browse toggle, the home-dir write flag and the filesWrite setting, while keeping the "files"-named infrastructure that carries remote session attach and chat CORS.

Purpose: the daemon no longer serves a files API or files capability (ROADMAP success criterion 5), and the path-traversal surface of the file sandbox disappears (ASVS V12).
Output: smaller daemon/relay/webserver route tables, read/read,write caps only, negative route tests, legacy settings fixture test.
</objective>
