## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan removes the file browser/editor from every UI surface (desktop and web share). Plan 01-03 removes the daemon API and capability behind it.

<objective>
Remove the file browser/editor UI end to end: tab type, menu entries, Hub card entry, remote-browse flow, web-share file panels, Share-dialog browse toggle, home-dir write warning, CodeMirror dependencies, CSS, help text and file-browser e2e specs.

Purpose: removes the user-reachable surface first so the backend removal in 01-03 cuts only dead code (outside-in removal keeps the app fully working after each plan).
Output: frontend with no file-browser code, updated bindings/tests/e2e/TESTING.md.
</objective>
