## Phase Goal

The app is a plain macOS terminal: new sessions run macOS zsh (`/bin/zsh -l`), no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim. It is not in user-story form and no story is invented here.)

This plan delivers ROADMAP success criterion 7 (NET-01) per CONTEXT Amendment 1 ("Tailscale: detect, don't manage"). It then closes Phase 1 with the full phase gate and the final TESTING.md reconciliation, salvaged from the old 01-10 plan.

<objective>
Reduce Tailscale handling to one LocalAPI connected/not-connected check. Show the NET-01 banner and disable the Share and remote/peer controls with the same reason while disconnected. Recheck at launch, periodically and on window focus. Delete the brew install flow, binary-path detection, macsys probes and multi-state health UI. Then run the whole phase gate and reconcile TESTING.md.

Purpose: CONTEXT Amendment 1 (Portty only checks for a working connection through the existing LocalAPI; remove the install flow, the custom binary path, the macsys probes and the multi-state health UI; keep LocalAPI for peers, certs and Funnel) and REQUIREMENTS NET-01. The final gate covers ROADMAP success criterion 5 and STRP-04.
Output: slim TailscaleHealth plus tests, the TailscaleBanner and the shared reason copy, disabled share/remote controls, focus recheck, no install flow, a passing phase gate and a reconciled TESTING.md.
</objective>
