## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Plain `wails build` | Without `-tags wailsassets` the window is blank (broken logo) | blocking | Always build with `wails build -platform darwin/arm64 -tags wailsassets` (or `./build.sh`); restore `frontend/src/wailsjs/wailsjs/` afterwards |
| Trusting LSP diagnostics | LSP in this repo is stale | advisory | Ground truth: `go build ./... && go vet ./...`, `go test -race -short ./...`, `cd frontend && pnpm exec tsc --noEmit && pnpm exec vitest run` |
| Default dispatch isolation | origin/HEAD makes default isolation "harness-worktree" | advisory | Force `query dispatch-isolation --force-isolation none` for executors |
| Testing GUI relaunch via Quit GUI Only / SIGTERM | Quit GUI Only hides to tray; GUI ignores SIGTERM | advisory | Use `kill -9 <gui pid>` to test daemon persistence |
