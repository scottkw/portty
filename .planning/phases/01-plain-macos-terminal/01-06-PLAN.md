## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan replaces the agent working/waiting status model with running / exited / errored everywhere (STRP-01 status half) and keeps exit behavior intact.

<objective>
Delete the agent output heuristics (internal/status) and derive status from process state in the daemon; render the three-state status per UI-SPEC on tab dots, the exit toast and the Hub (cards, filter bar, empty states, modal); treat legacy/unknown values as running.

Purpose: CONTEXT "Status model shrinks to running / exited / errored"; UI-SPEC section 2 and Color table (colorblind-safe shapes).
Output: derived status in Go, shared status normalizer in TS, UI-SPEC status visuals and copy, no pill group.
</objective>
