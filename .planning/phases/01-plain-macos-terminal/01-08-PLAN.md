## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan keeps per-session chat on desktop and web while removing the @session agent-inject bridge (CHAT-01), and gives relay and webserver the fuzz coverage STRP-04 asks for (resolved question 1).

<objective>
Delete the chat-to-PTY inject bridge end to end (both read-pump cases, hub machinery, wire types, PTY sanitizer, frontend @session target and indicator), retarget the inject security tests into "0x35 never reaches the PTY" tests, and add small fuzz targets for relay frame parsing and webserver request/path handling.

Purpose: CONTEXT "Chat: remove the @session pinned target and the chat→PTY inject bridge, including its server-side endpoint. Keep @alias mentions, presence, typing, export, and unread badges." Security-sensitive read pumps get their own plan (RESEARCH suggested order, plan 4).
Output: no inject code, retargeted security tests, legacy history test, 5 fuzz targets, updated e2e/help/TESTING.md.
</objective>
