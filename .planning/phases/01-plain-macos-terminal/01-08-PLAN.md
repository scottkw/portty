## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan finishes STRP-01's identity removal on the Go side: daemon, webserver, e2e fixture, tailnet peer metadata, CLI listing and the attach status bar. Plan 01-07 already made the frontend stop reading the field.

<objective>
Remove the session agent/CLI field from every Go wire type and CLI surface, and replace the webserver's empty-cliType "not found" sentinel with an explicit found flag so unknown sessions still 404.

Purpose: CONTEXT "Remove the agent/CLI field from the session API, daemon state, and persisted session data" and RESEARCH Coupling C4 / Pitfall 7.
Scope note (checker scope_sanity): of the 22 files, 9 are test files whose edits follow the source change (one new 404 regression test and one legacy-peer decode test; the rest drop the agent column or field from expected output), 1 is TESTING.md, and most of the 12 source edits are single-field or single-argument deletions; the substantive change is the resolver signature in internal/webserver/server.go and its three implementers (api.go closures, capability_test_helpers.go, the playwright fixture).
Output: no cli/CLIType/cli_type/AgentType in Go, explicit 404 contract, legacy peers still decode.
</objective>
