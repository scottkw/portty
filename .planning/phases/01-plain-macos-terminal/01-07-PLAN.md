## Phase Goal

The app is a plain macOS terminal: new sessions run the user's login shell, no agent-CLI, file-browser, or Windows/Linux code remains, and every kept feature still works. (ROADMAP Goal, verbatim; not in user-story form, no story invented.)

This plan removes the last agent identity from every surface and wire format (STRP-01) and keeps the one-time raw-shell web-share warning working now that every session is a shell.

<objective>
Remove the session agent/CLI field from the frontend, the daemon and webserver wire, tailnet peer metadata, the CLI listing and the attach status bar; delete agent badges and their palettes; re-gate the web-share warning on enabled && not-yet-warned and rename its secondary button.

Purpose: CONTEXT "Remove the agent/CLI field from the session API, daemon state, and persisted session data" plus UI-SPEC section 3. Ordered outside-in (frontend stops reading first, then Go stops sending) so every commit leaves a working app.
Output: no cli/cliType/cli_type/AgentType anywhere, explicit 404 contract, UI-SPEC warning copy.
</objective>
