<objective>
Let the remote user pick a whole display or a single window and switch mid-session without reconnecting (DESK-05, DESK-06): a surfaces list and select message on the signalling socket, a live switch of the running ScreenCaptureKit stream with an encoder rebuild and a forced keyframe, an epoch bump that drops stale input, and a fallback to the main display when the shared window or display goes away.

Purpose: one shared encoder and track per share (19-CONTEXT), so a switch is per share and every viewer sees it; viewers never learn display layout or window position because they send normalized coordinates (CONTEXT Input wire protocol).
Output: surface.go (desktop), surfaces.go and the native switch (screencap).
Scope note: 10 files because a switch spans the native capture (media_darwin.m/.go, surfaces.go) and the daemon's signalling (surface.go, manager.go); 4 of them are tests (surfaces_test.go, screencap_darwin_test.go, surface_test.go, protocol_test.go).

Decisions implemented: CONTEXT [Surface] (switch on the running stream, no renegotiation; not persisted), [Mapping] (displays by bounds, windows by frame, rebuilt on reconfiguration), [Logging], [Testing]; Claude's Discretion (picker in the viewer; window list format including Portty's own; fallback notice to the main display).
</objective>
