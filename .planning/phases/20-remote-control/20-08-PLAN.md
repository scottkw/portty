<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| viewer clipboard to the Mac | the viewer's clipboard may hold anything; it leaves only on Paste to Mac |
| Mac text into the viewer page | text from the Mac lands in the browser clipboard or a popover |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-39 | Information disclosure | viewer clipboard | high | mitigate | readText and write only inside the user's click on the menu item or popover button; no polling, no listener on copy or paste events outside the popover |
| T-20-40 | Information disclosure | clipboard text at rest | medium | mitigate | Text lives only in memory for the transfer or inside the open popover; never logged (grep criterion) or stored |
| T-20-41 | Tampering | chunk assembly | medium | mitigate | xid, seq, total and len checked; gaps and duplicates fail; 1 MiB cap before sending; frames under the read limit |
| T-20-42 | Tampering | injected markup | medium | mitigate | Clipboard text renders only as textarea value, never HTML |
| T-20-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is added by this plan |
</threat_model>
