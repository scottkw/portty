<objective>
Text moves between the viewer's clipboard and the Mac's only by an explicit action (DCTL-06): Copy from Mac reads the Mac's pasteboard on request, checks types first so password-manager items never leave, and streams the text in chunks under the socket read limit; Paste to Mac reassembles chunks and sets one plain string.

Purpose: an unattended Mac must never hang on a privacy prompt nobody can click, and a password manager's item must never be exfiltrated.
Output: clipboard.go and the pasteboard bridge.

Decisions implemented: CONTEXT Clipboard and permissions (explicit read, types first, waiting for approval instead of hanging; the VM measurement itself is 20-09), [Clipboard] (utf8 plain text only, concealed and transient skipped, plain string write), [Limits] (1 MiB, chunks), [Logging]; Claude's Discretion (Paste to Mac never presses Cmd+V; Cmd+C/Cmd+V typed are keys; chunks near 16 KiB).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mac pasteboard to viewer | the Mac's clipboard can hold secrets from a password manager |
| viewer text to Mac pasteboard | untrusted text replaces what the user copied at the Mac |
| daemon to macOS privacy prompt | a read may wait for a click nobody can give |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-25 | Information disclosure | concealed items | high | mitigate | Types checked before any content read; ConcealedType, TransientType and the 1Password type answer concealed; TestClipboardTracer_CopyFromMac asserts no content was requested |
| T-20-26 | Information disclosure | background sync | high | mitigate | Read only on clip_get, write only on a completed clip_put; no changeCount use (grep criterion); Cmd+C and Cmd+V stay keys |
| T-20-27 | Denial of service | privacy prompt hang | high | mitigate | accessBehavior alwaysDeny answers without reading; reads bounded by 2 s on a separate goroutine; one read in flight per process; TestClipboard_WaitingApproval |
| T-20-28 | Tampering / DoS | paste reassembly | medium | mitigate | Strict seq, xid, total and len checks, 16 KiB chunks, 1 MiB cap refused before buffering, UTF-8 validation, discard on any error or disconnect |
| T-20-29 | Elevation of privilege | per-viewer clipboard right | medium | mitigate | RightsClipboard checked per action, failed while locked; Phase 22 grants clipboard per person |
| T-20-30 | Information disclosure | logs | medium | mitigate | Outcome and byte count only; grep criterion forbids text in log calls |
| T-20-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is added by this plan |
