## Wire contract frozen here (input protocol 1, additive to signalling protocol version 1)

Data channel `input` (viewer to daemon, one JSON object per message, `t` discriminates, unknown fields ignored, unknown `t` is a counted drop, at most 4096 bytes):
- `move {x, y, e}`: normalized 0..1 of the shared surface (finite numbers clamped to 0..1), `e` the surface epoch.
- `rmove {dx, dy, e}`: relative move in normalized surface units (Phase 21 trackpad).
- `btn {b, d, x, y, e, ts}`: browser button index (0 left, 1 middle, 2 right), `d` true down / false up, position, viewer `performance.now()` ms.
- `wheel {dx, dy, e}`: pixel deltas, browser sign (dy > 0 scrolls down).
- `key {code, d, r, m, caps, k, ts}`: W3C code, down, repeat, modifier mask m (1 shift, 2 ctrl, 4 alt, 8 meta; 0..15), Caps Lock state, the typed character `k` (carried and validated; the daemon does not type from it), timestamp.
- `text {s}`: composed text, 1..1024 UTF-8 bytes, valid UTF-8.
- `hb {}`: heartbeat while anything is held. `release {}`: release everything this viewer holds.
Daemon to viewer on the same channel: `control {input: "ok"|"needs_accessibility", window: ""|"raise_failed"|"minimized"}` and `cursor {x, y, e}` (implemented in 20-02).
Signalling additions (/desktop/ws, `type` discriminates): viewer hello `caps {video:1, input:1}`; server hello adds `caps.input: 1` and `rights {control, clipboard, surface}`; `surfaces` request and reply `{displays:[{id,name,w,h,main}], windows:[{id,app,title,name}]}` or `{error:"list_failed"}`; `select {kind:"display"|"window", id}` (display id 0 means the main display); `surface {e, kind, id, name, w, h, reason:""|"window_closed"|"display_gone"}`; `select_failed {code:"switch_failed"|"not_found"|"busy"|"forbidden"}`; `clip_get {xid}`; `clip_put {xid, seq, total, len, text}`; `clip_data {xid, seq, total, len, text}`; `clip_result {xid, outcome:"ok"|"concealed"|"empty"|"too_large"|"waiting_approval"|"failed"|"forbidden"|"busy"}`. Clipboard messages name their transfer `xid` (a string), never `id`, because `select` already uses a numeric `id` and the server decodes every viewer frame into one struct. `len` is the total UTF-8 byte length; `text` in one chunk is at most 16384 bytes and the encoded frame at most 30000 bytes, under the 32768-byte read limit. ProtocolVersion stays 1.
