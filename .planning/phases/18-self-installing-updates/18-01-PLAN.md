2. internal/updater/appinstall.go (new). Declare `ErrInstall = errors.New("install failed")`, `BundleName`, `StagingPrefix`, `BundleExecutable` and `StageInput` as listed in the Artifacts section. Every failure wraps ErrInstall with a step name and never a path: `mount`, `detach`, `copy`, `app-codesign`, `app-team`, `quarantine`.
   - `Mount`: run `/usr/bin/hdiutil attach -nobrowse -readonly -noverify -noautoopen -mountpoint MOUNTDIR DMG` (exec gives stdin /dev/null, so a license prompt cannot block); then Lstat `MOUNTDIR/Portty.app` must be a directory (not a symlink), else detach and return step `mount`. Choosing the mount point ourselves means no plist parsing on this path.
   - `Detach`: run `/usr/bin/hdiutil detach MOUNTDIR`, then `os.Remove(MOUNTDIR)` ignoring not-exist (Task 2 adds the retries, `-force` and the already-gone case).
   - `CopyApp`: `os.MkdirTemp(filepath.Dir(target), StagingPrefix)` (mode 0700), staged path is that dir plus `Portty.app`, run `/usr/bin/ditto SRC STAGED` (never cp, never a Go tree walk); on error RemoveAll the staging dir and return step `copy`.
   - `VerifyApp`: `/usr/bin/codesign --verify --deep --strict APP` (step `app-codesign`), then `/usr/bin/codesign -dvv APP` must contain the whole line `TeamIdentifier=` + TeamID via hasLine (step `app-team`). 18-02 extends this function; keep it the single place app signatures are checked.
   - `Stage(ctx, run, in)`: ClearQuarantine(in.DMG); MkdirTemp(in.MountRoot, "mnt-"); Mount; VerifyApp on the mounted app; CopyApp(mounted app, in.Target); ClearQuarantine(staged); VerifyApp(staged); Detach. After a successful Mount, Detach runs on every return path; any failure after CopyApp removes the staging dir. Quarantine is cleared from the staged copy only after the mounted app passed VerifyApp and the DMG passed Verify (UPD-09). Returns the staged app path.
