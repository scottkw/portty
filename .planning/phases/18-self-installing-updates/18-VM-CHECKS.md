- **Method:** `.planning/phases/18-self-installing-updates/rig/p18-rig.sh` (`build`, `deploy-n`, `dmg`, `feed`, `state ROW`, `quit-gui`, `clean`). The fake feed is `cmd/fakegh` on `127.0.0.1:8788` inside the VM; the `vmpreview` build's `$HOME/p18/verify-mode` file (`adhoc`) fakes only the codesign and spctl answers, every other tool runs for real. Sessions are made with the installed CLI (`portty new`, `portty rename`) and typed into through the 09 expect driver (`cli.exp`, pointed at `/Applications/Portty.app`); the second session runs `vim -u NONE -N -S ~/p18/vtick.vim` (a timer appends a `VTICK n` line every second). A VM-side poller samples the GUI pids, the daemon `/health` version and the installed version every 0.4 s, and a second poller lists the on-screen windows (CGWindowList through `osascript -l JavaScript`) every second. The GUI is read with `~/ptest/axdump`, clicks use `~/ptest/click`.
- **Host safety:** every `rm`, `hdiutil`, `ditto`, `open` and DMG creation ran inside the VM through `vm.sh`. The host built, wrote evidence files and sent tar streams over ssh. Nothing on the host was mounted, opened or copied from `~/Downloads` or `/Applications`; the host's `/Applications/Portty.app` was never touched; no host tailscaled or 100.x address was contacted.
- **Evidence:** `evidence/ROW.state` files are written verbatim by `p18-rig.sh state ROW` (VM home shown as `~`, no hand edits). Header line `p18-state row=ROW vm_utc=TIME`.
