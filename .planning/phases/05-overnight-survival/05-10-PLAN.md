## Flagged decisions and assumptions

- Mechanism (Claude's discretion; supersedes the CONTEXT "no NSWorkspace wake hook" decision per the user's requirement): a pure-Go detector, not an AppKit NSWorkspace observer. Why: `portty attach` runs in a terminal with no AppKit run loop (NSWorkspace notifications never arrive there), the GUI and CLI can share one detector, it needs no cgo, and it is testable with an injected clock. Sleep detection compares wall-clock time between consecutive ticks of a 2 s ticker (`time.Now().Round(0)` strips the monotonic reading): a gap over interval + 3 s means the machine slept or the process was stopped. This works whether Go's darwin monotonic clock pauses in sleep (mach_absolute_time, today, RESEARCH Pitfall 9) or not, because a ticker that missed its ticks still fires once on wake and the wall gap is the sleep length. Network change: compare a sorted key of `net.InterfaceAddrs()` minus loopback and link-local (fe80::/10, 169.254/16) each tick.
- Public API (05-13 depends on it): package `wakewatch`; `type Reason string`; `const Woke Reason = "wake"`, `const NetworkChanged Reason = "network"`; `func Watch(ctx context.Context) <-chan Reason` (channel buffered 1; a send never blocks; a pending event is not duplicated; closed when ctx ends).
- Loop semantics mirror the GUI's 05-04 rule: a wake-triggered death dials at once (no backoff wait for that attempt) and the backoff restarts from attempt 0. New Timing fields: `ProbeGrace` (5 s) and `WakeMinGap` (5 s); DefaultTiming gains both. A nil `RunOptions.Wake` means no wake events (local attaches and existing tests).
- Typing while disconnected stays dropped (CONTEXT [Reconnect] "Input stays disabled; keystrokes never queued"; 05-06 stale-chunk stamping is kept).
- Every Go command runs with `GOTOOLCHAIN=go1.26.11` (05-11 pins it; Go 1.27 breaks tailscale.com v1.98.3 JSON).
