## Flagged decisions and assumptions

- **Why a new tag, not vmpreview.** `vmpreview` (share_vmpreview.go) replaces the whole share server with a loopback one for VMs without Tailscale; the VM rows in 14-12 run over the real tailnet, so they need the real tailnet server with only the WhoIs answer changed. `vmwhois` wraps `defaultNewShareServer`; nothing else changes.
- **The wrapper (internal/daemon/share_vmwhois.go, `//go:build vmwhois`).** A small type holding the real `local.Client` and the mode file path (`$HOME/p14/whois-mode`, read on every call; content `other`, `pass` or `fault`; a missing or empty file means `other`; any other content means `fault`, fail closed). `StatusWithoutPeers`: an error in `fault`, else the real answer. `WhoIs`: an error in `fault`; the real answer in `pass`; in `other`, the real answer unless its `Node.StableID` equals the real self status's `Self.ID`, in which case it passes unchanged; otherwise a copy of the response and node with `User` set to the self user plus 1000 (never mutate the client's structs). `init()` keeps the previous `defaultNewShareServer` and installs the wrapper on every server it returns via `SetWhoIsClientForTest`. Header comment in the share_vmpreview.go style: VM only, never in a release, check-brand enforces it. It imports nothing from the webserver test package. Log one debug line per decision with numeric IDs only.
- **Release guard (repo root, package main, `release_guard_test.go`).** `TestNoFakeWhoIsInRelease` runs `go list -deps` on `.` with no tags, with `-tags wailsassets` and with `-tags vmwhois`: each output contains `github.com/scottkw/portty/internal/webserver` (so the check is not vacuous) and does not contain `internal/webserver/webservertest`; then `go list -deps -tags playwrightfixture ./cmd/playwright-fixture` does contain it (positive control). Every `go list` runs through one helper, `goListDeps(tags, pkg string) (string, error)`, which captures stdout and stderr separately with `exec.Command` and returns an error carrying the arguments, the exit status and stderr when the command fails to start or exits non-zero. The test calls `t.Fatalf` on any such error before searching the output (a broken `go list` must fail the guard, never read as "fake absent"); the positive control goes through the same helper. `go` missing from PATH fails the test (no skip).
- **check-brand (header convention: every pattern spells its word with one bracket class).** Add a `fake-whois` check: `git grep -n -I` for the import path of webservertest spelled with `webserver[t]est`, over `*.go` excluding `*_test.go`, `cmd/playwright-fixture/` and `internal/webserver/webservertest/`. Extend the existing `vm-tag` check's pattern to `vmpr[e]view|vmwh[o]is` with `-E`. Update the header list.
- **Fixture routes (build tag playwrightfixture; admin listener is plain HTTP on 127.0.0.1 only).**
  - Grid: pass a resize function to `manager.Create` that stores the last `(cols, rows)` and counts calls; `GET /__test__/grid` returns `{"cols":…,"rows":…,"resizes":…}`.
  - Info hits: the session resolver counts calls for the fixture session (it runs only after the capability check passes); `GET /__test__/info-hits` returns `{"count":…}`.
  - `POST /__test__/share-off`: `ClearGrants`, `DisableSession`, then the hub's `RevokeWebViewers(relay.CloseReasonShareStopped)` (the daemon's order, as revoke_test.go's revokeShare shows).
  - `POST /__test__/share-on`: `EnableSession`, a new grant id, `AddGrant`, sign a `read,write` capability; returns `{"cap":…}`.
  - `POST /__test__/end`: close the PTY output pipe writer so the hub ends and live sockets close with the session-ended reason (check which call produces that reason; use it).
  - `POST /__test__/preview-pdf`: send a small valid PDF (a fixed byte literal in the fixture, a few hundred bytes, one blank page) through `hub.SendPreview` with the fields internal/relay/preview.go requires.
  - CA: `selfSignedTLS` also returns the CA certificate PEM; when `PLAYWRIGHT_FIXTURE_CA_PEM` names a path, write the PEM there (0644) before READY and print `CA_PEM=<path>`. The private key is never written.

  - Never run anything on the host that talks to the host's live tailscaled or a 100.x address. The wrapper's tests use a fake inner client; the tagged build runs only in the VMs (14-12).
  - Logs live in a private `mktemp -d` directory, printed by the verify and recorded in the SUMMARY. Never pipe a test run through `tail` or `head`. Targeted packages only here (14-03 runs the full Go suite in this wave; 14-12 runs the full gate).
