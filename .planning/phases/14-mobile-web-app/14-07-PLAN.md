## Flagged decisions and assumptions

- **Why now.** The manifest (14-05) and the fixture's CA, info-hits and share routes (14-06) are what the spike needs. The key bar does not exist yet, so the signal is the fixture's `GET /__test__/info-hits`: the SPA calls the info route only when the launch URL carries both `session` and `cap` (with either missing it shows Link No Longer Works at once and fetches nothing), and the fixture counts only info requests that passed the capability check.
- **Headless only.** `UDID=$(xcrun simctl create portty-p14-spike "iPhone 17" <the iOS 26.5 runtime id from xcrun simctl list runtimes>)`, `xcrun simctl boot "$UDID"`, `xcrun simctl bootstatus "$UDID" -b`. Never `open -a Simulator`, AppleScript or host input events. Record `pgrep -x Simulator` at the start and end (expected empty; if the user had it open, record that and leave it alone). Screenshots with `xcrun simctl io "$UDID" screenshot` into `SHOTS=$(mktemp -d -t p14-spike-shots)`; they are not committed (Safari's address bar can show the fixture link); list their names and sha256.
- **Fixture over TLS.** In `S=$(mktemp -d -t p14-spike)`: `pnpm --dir frontend install --frozen-lockfile --prefer-offline`, `pnpm --dir frontend exec vite build`, replace `cmd/playwright-fixture/dist` (gitignored) with a copy of `frontend/dist`, `GOTOOLCHAIN=go1.26.11 go build -tags=playwrightfixture,wailsassets -o "$S/fixture" ./cmd/playwright-fixture`, launch with `PLAYWRIGHT_FIXTURE_CA_PEM="$S/ca.pem"`, stdout to a 0600 file; `xcrun simctl keychain "$UDID" add-root-cert "$S/ca.pem"`. The app link (`BASE_URL/app/?session=playwright-test-session&cap=<CAP>`) lives only in a 0600 file. The fixture's certificates last two hours.
- **Runner (throwaway, never committed).** In `$S/runner`, a `project.yml` for the installed xcodegen: an iOS 26 app target `P14Host` (empty SwiftUI app, the UI test host) and a `bundle.ui-testing` target `P14UITests` with a scheme, ad-hoc simulator signing; `xcodegen generate`; `xcodebuild build-for-testing -derivedDataPath "$S/dd" -destination "platform=iOS Simulator,id=$UDID"`; run methods with `test-without-building -only-testing:` and `TEST_RUNNER_P14_APP_URL` / `TEST_RUNNER_P14_ADMIN_URL`. Tests drive `com.apple.mobilesafari` and `com.apple.springboard`, open the link with `XCUIDevice.shared.system.open(_:)`, read the admin routes with URLSession, and dump `debugDescription` to `$S` when an element is missing. If the runner cannot be built or cannot drive Safari after three distinct fixes, write H-00 as FAIL with `rig:` evidence, H-01 as FAIL `rig: not run`, clean up, and go to the checkpoint.
- **Rows (`| Check | Result | What was checked | Evidence |`, Result exactly PASS or FAIL):**
  - H-00 (preflight): Xcode version, runtime id, device type, UDID created and booted headless, `pgrep -x Simulator`, fixture READY, CA added, runner built.
  - H-01 (M-145 spike): open the link in Safari and wait for the page; Share, then Add to Home Screen: the name field reads "Portty" (from the manifest and apple-mobile-web-app-title) and Open as Web App is on; Add. Read info-hits (N). On SpringBoard tap the "Portty" icon; within 10 s read info-hits again and take a screenshot. PASS (query kept) when it is N+1 and the screenshot shows the share view with no Safari address bar and no Link No Longer Works; FAIL with `query dropped` when it stays N and Link No Longer Works shows. Record the standalone process's bundle identifier if found (`xcrun simctl spawn "$UDID" launchctl list` filtered for web app processes).
- **Cleanup.** `xcrun simctl shutdown` and `xcrun simctl delete` the device (the CA trust and the icon go with it), stop the fixture, delete `$S`; keep `$SHOTS` for the checkpoint (14-14 deletes it with the other screenshots).
- **Executor constraints (every Phase 14 plan carries these):**
  - Every Go command runs with `export GOTOOLCHAIN=go1.26.11`. Confirm 14-05 and 14-06 SUMMARY files exist first; if either is missing, stop.
  - Never run anything on the host that talks to the host's live tailscaled or a 100.x address. Everything here is loopback.
  - Stage only `.planning/phases/14-mobile-web-app/14-SIM-CHECKS.md`. Never stage `.gitignore`, `.planning/state.json`, `.ignore`, `agenthub/`, `cmd/playwright-fixture/dist` or anything under `$S`. Plain `git commit`, ending with the commit attribution in effect at execution time.
  - No product code changes, no package install, no host user defaults changed, no Simulator.app launch.
