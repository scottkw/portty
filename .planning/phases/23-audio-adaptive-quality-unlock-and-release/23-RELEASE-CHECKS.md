# Phase 23 release checks: v2.0.0-rc.1 and v2.0.0-rc.2 dry runs

Plan 23-13. The pipeline is Phase 18.1's (`.github/workflows/release.yml`, `scripts/verify-bundle.sh`, `internal/updater`); this plan runs it and changes none of it. The user, not Claude, pushes the tags. Downloads go to a scratch directory in the session scratchpad (never ~/Downloads); each DMG is mounted with `hdiutil attach -readonly -nobrowse` on a scratch mountpoint and detached afterwards; nothing from a DMG is opened, installed or run on the host. Evidence carries no token or credentialed URL.
