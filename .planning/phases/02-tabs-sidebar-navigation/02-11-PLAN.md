## Phase Goal

Users navigate everything from tabs plus a sidebar: the Hub grid is gone, and the sidebar lists local sessions and tailnet peers' sessions, each opening in a tab. (ROADMAP Goal, verbatim.)

This plan completes the native look for Settings (ROADMAP SC8, LOOK-01). It finishes "no theme picker" (SC7, THEM-01) and removes the last non-session tab type (SC1, NAV-03).

<objective>
Re-host Settings as a sheet over the main window, styled as a macOS grouped form with General, Sharing and Security panes. Add one switch component, show every disabled reason inline, and delete the Settings tab type, jump bar and search.

</objective>
