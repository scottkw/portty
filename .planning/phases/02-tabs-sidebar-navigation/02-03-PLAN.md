## Phase Goal

Users navigate everything from tabs plus a sidebar: the Hub grid is gone, and the sidebar lists local sessions and tailnet peers' sessions, each opening in a tab. (ROADMAP Goal, verbatim.)

This plan delivers ROADMAP success criterion 7 (THEM-01) and the token and system-font half of success criterion 8 (LOOK-01). Every later plan styles against these tokens.

<objective>
Replace the 138-theme library and the manual UI-theme toggle with one hook that follows prefers-color-scheme. It feeds one built-in light and one built-in dark terminal palette to every terminal on the desktop and on the web share page. style.css gets the UI-SPEC colour tokens in two blocks (light on :root, dark in a prefers-color-scheme media block). The old --hub-* tokens become aliases, and the UI and terminal fonts switch to the system fonts.

Purpose: CONTEXT ▸ Light/Dark, Chat & Cuts (one dark and one light ANSI palette; live switch on prefers-color-scheme; web share page follows the browser; the theme library, picker and key removed) and CONTEXT ▸ Window & Chrome (system font and SF Mono; every colour a CSS variable with one light and one dark set). Orchestrator resolved default 7: the themes live in localStorage, not settings.json, so stale keys are ignored and no Go settings change is needed.
Output: useColorScheme.ts, terminalPalettes.ts, the token blocks, a token source gate, a web e2e spec, the theme picker removed, fonts switched, xterm-theme and the bundled fonts deleted.
</objective>
