# Phase 02 — UI Design Contract

> Visual and interaction contract for Phase 2 (Tabs + Sidebar Navigation, LOOK-01, THEM-01, CHAT-01). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Sources, in priority order:**
1. `02-CONTEXT.md` decisions. These are locked, and they override the mockup where the two disagree.
2. The approved mockup (user: "The redesign looks great"): `Main.dc.html` and `Settings.dc.html` (scratchpad `portty-design/project/`). Its layout, palette, sizes and copy are locked design decisions. Values were snapped to the 4px grid where the mockup used odd numbers. Each deviation is listed in "Deviations From the Mockup".
3. `01-UI-REVIEW.md` findings that Phase 2 must fix: the banner's hardcoded hex values, the `⚠` glyph, off-scale spacing, disabled reasons shown only in tooltips, and the unstable accessible name on the disabled Share button.
4. Existing code: `frontend/src/style.css`, `App.tsx`, `Sidebar.tsx`, `TabBar.tsx`, `SettingsTab.tsx`, `PluginsSection.tsx`, `SessionShareModal.tsx`, `RemoteJoinCodeModal.tsx`, and `main.go`.

## Typography

UI type scale: exactly 4 sizes and 2 weights.

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Label | 11px | 600 | 14px (1.27) | Sidebar group headers ("This Mac", peer hostnames), Settings pane-tab labels, section headers above Settings groups, field labels in the Share dialog |
| Caption | 12px | 400 | 16px (1.33) | Settings row descriptions, sidebar footer, muted sidebar lines, banners, the "On <host>" chip, the ⌘T hint, mono URLs and codes (`ui-monospace` at 12px) |
| Body | 13px | 400, or 600 for emphasis | 18px (1.38) | Sidebar rows, tabs, buttons, menu items, Settings rows, dialog body. Weight 600 only for the active tab label, dialog and sheet titles, and the Settings sheet title |
| Display | 17px | 600 | 22px (1.29) | Empty-state heading only |

The 12px step is intentional: it is the macOS secondary-text size, one step below the 13px body, and the mockup uses it for every description, footer and banner. The line heights follow macOS (AppKit) text metrics, which are tighter than web defaults on purpose. Terminal text is user content and sits outside this scale: xterm draws it at 13px default with ⌘± zoom, and xterm's own bold.

A `matchMedia('(prefers-color-scheme: dark)')` change listener sets `term.options.theme` on every open terminal (desktop tabs, peer tabs, web share page) with no restart and no reload. `allowTransparency` stays off, so the WebGL renderer draws an opaque background.

- Focal point: the active terminal is the visual anchor of the main window (the largest area, on the dominant surface). The selected sidebar row (accent fill) and the active tab pill (neutral fill, 600 weight) tell the user which session that terminal belongs to. Nothing else in the chrome competes with them.
- `nav[aria-label="Sessions"]` (sidebar) | `main` (toolbar, banner stack, terminal container).
- The banner stack moves from the top of the window into `main`, between the toolbar and the terminal, full width of the content column.
- No bottom status bar. `StatusBar.tsx` is removed: Share moves to the toolbar and Tailscale status moves to the sidebar footer.
- No Hub, Home, Welcome, Help or Settings tabs. The tab strip only ever holds session tabs.
- Window minimum stays 800×600 (552px content column with the sidebar shown).

### Web share page (browser, `mode === 'web'`)

- No sidebar, no traffic-light inset, no drag regions.
- The toolbar (52px, `--color-toolbar`) shows the one session as a static active tab pill: no close button, no "+" button, no Share button, no context menu.
- The terminal fills the rest of the page. No chat overlay.
- Tokens and terminal palette follow the browser's `prefers-color-scheme` live, with the same values as the desktop app.

## Accessibility Contract

- Landmarks: `nav[aria-label="Sessions"]` and `main`. The tablist uses `aria-label="Open sessions"`, and each tab's `aria-controls` points at its terminal panel.
- Tabs: ←/→ move focus between tabs (ARIA tabs pattern), Enter or Space activates, Shift+F10 opens the tab menu.
- Sidebar rows are buttons reachable by Tab. The active row has `aria-current="page"`. "Shared" is announced through the icon's `role="img"`.
- Status changes (Tailscale banner, footer) use `role="status"`.
- Disabled-with-reason controls use `aria-disabled` plus `aria-describedby`, never `disabled` plus a tooltip alone (UI-REVIEW 01 #2 and #3).
- Every dialog has `role="dialog"`, `aria-modal="true"` and `aria-labelledby` pointing at its title, with focus trapped inside.
- The Tailscale dot is never the only signal: text always accompanies it.
