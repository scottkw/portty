## Phase Goal

Users navigate everything from tabs plus a sidebar: the Hub grid is gone, and the sidebar lists local sessions and tailnet peers' sessions, each opening in a tab. (ROADMAP Goal, verbatim.)

This plan delivers ROADMAP success criteria 4 (TERM-03) and 5 (Share reachable from any session tab), and the unified-toolbar part of 8 (LOOK-01).

<objective>
Turn the tab bar into the macOS unified toolbar: pill tabs, a New Session button, a Share button (or an "On <host>" chip for peer tabs) and scroll buttons. Closing a tab only detaches, and a separate confirmed End Session… ends the shell. Rename works in place in both the tab and the sidebar row, with one source of truth. Add a shared context menu, the empty state and ⌘W. Delete the bottom status bar.

Purpose: CONTEXT ▸ Sidebar & Tabs ("Closing a tab only detaches … Right-click 'End Session…' (with a confirm) kills it"; "Rename: double-click the name in the sidebar row or the tab … plus a right-click 'Rename' item. The new name shows in both places"; "No tabs open: a quiet empty state with a 'New Session' button (⌘T)"; Share disabled with the NET-01 reason visible on screen) and CONTEXT ▸ Settings, Help, Share & Status Bar ("a toolbar Share button opens the existing Share dialog"; "The bottom status bar is removed"). UI-SPEC "Toolbar and tabs", "Share button", "Context menus", "Inline rename", "Empty state", "Interaction Contract". RESEARCH Pattern 6, Pitfalls 3 and 6.
Output: TabBar as the toolbar, lib/tabs.ts helpers, ContextMenu.tsx, EmptyState.tsx, the End Session confirm, rename on both surfaces, StatusBar deleted, and TESTING.md.
</objective>
