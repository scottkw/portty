## Phase Goal

Users navigate everything from tabs plus a sidebar: the Hub grid is gone, and the sidebar lists local sessions and tailnet peers' sessions, each opening in a tab. (ROADMAP Goal, verbatim.)

This plan delivers the Go half of ROADMAP success criterion 6 (CHAT-01): no chat endpoint, store or wire frame remains, and old clients' chat frames are dropped without crashing anything. The frontend chat UI goes in plan 02-07, after the Hub tree that also renders it is deleted in plan 02-05. Until then the desktop chat panel stays on screen but does nothing (its history call 404s and its sends are dropped). Build and tests stay green.
