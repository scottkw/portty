# Phase 18.1 Plan 03: Release workflow on the Apple Silicon pipeline Summary

release.yml now builds once for darwin/arm64 with macOS 14 CGO flags, gates the bundle three times, signs inside out via sign-bundle.sh, and publishes the one build under both DMG names from a single `DMG_SUFFIXES` list, with Go tests pinning all of it.

## What was built

**Task 1 (tracer), commit c8436c52.** release.yml: validate runs `tests/verify-bundle.test.sh`; "Build macOS app" uses `wails build -platform darwin/arm64 -tags wailsassets` with `CGO_CFLAGS` and `CGO_LDFLAGS` = `-mmacosx-version-min=14.0`; new step "Release bundle is arm64-only with minos 14.0 (REL-01)" runs `verify-bundle.sh` before the tar; unsigned artifact renamed `portty-darwin-arm64-unsigned` on upload and download; the deep codesign call is replaced by `sign-bundle.sh` plus `verify-bundle.sh --signed`; "Notarize .app" ends with `verify-bundle.sh --notarized`. New tests `TestReleaseWorkflow_Arm64Build`, `TestReleaseWorkflow_InsideOutSigning`, `TestBuildWorkflow_Arm64MinOS14`, `TestVerifyBundle_PinsTeamAndDR`, plus helpers `readRepoFile` and `before`.

**Task 2, commit 27b2347f.** Final suffix line:

```

  DMG_SUFFIXES: "darwin-universal darwin-arm64"

Tests rewritten/added: `TestReleaseWorkflow_DMGName` (names derived for v1.2.3: `portty-v1.2.3-darwin-universal.dmg`, `portty-v1.2.3-darwin-arm64.dmg`, equal to `DMGAssetNames("1.2.3")` in order), `TestReleaseWorkflow_NotarizesAndStaplesDMG`, `TestReleaseWorkflow_SignTimeout`, `TestReleaseWorkflow_ChecksumsAndNotes`.
