## Gap 4: The v1.2 designated requirement (re-verified today)

Method: `gh release download v1.2.0 -p '*darwin-universal.dmg'` into a scratch directory (sha256 `3d9b684044a9fb0d821411c7b1e0555fac1e0ba3251b9728ddbe38d2cc99f2fa`, equal to GitHub's published digest), `hdiutil attach -nobrowse -readonly -noverify -mountpoint <scratch>`, inspect, `hdiutil detach`; `hdiutil info` afterwards shows no scratch image.
```
codesign -d -r- Portty.app 2>&1 | grep designated
designated => identifier "app.portty.Portty" and anchor apple generic and certificate 1[field.1.2.840.113635.100.6.2.6] /* exists */ and certificate leaf[field.1.2.840.113635.100.6.1.13] /* exists */ and certificate leaf[subject.OU] = S2K7P43927
```
Other observed facts for v1.2.0: `Identifier=app.portty.Portty`; `flags=0x10000(runtime)`; `Authority=Developer ID Application: Ken Scott (S2K7P43927)`; `TeamIdentifier=S2K7P43927`; slices `x86_64 arm64`, arm64 `minos 11.0` (not 10.13: the linker clamps); `LSMinimumSystemVersion` 10.13.0; `stapler validate` worked; `spctl -a -t exec -vv` printed `accepted`, `source=Notarized Developer ID`; one Mach-O in the bundle (Contents/MacOS/Portty).

The DR is built from identifier + Apple CA chain markers (Developer ID Application leaf OID `...6.1.13`, Developer ID CA intermediate `...6.2.6`) + `subject.OU`. It does not depend on architecture, version, or signing order, so any Developer ID Application certificate of team S2K7P43927 with `--identifier app.portty.Portty` reproduces it, including after a certificate renewal. It does depend on the identifier: an ad-hoc signature with the same identifier yields `designated => cdhash H"..."`, which the gate must reject [VERIFIED: scratch ad-hoc copy]. Pin this string once, in `scripts/verify-bundle.sh`, matched with `grep -qxF` against the `designated => ` line (the command also prints an `Executable=` line, so filter by line). Team ID and the string are safe to commit (no home paths, no tailnet addresses).

## Common Pitfalls (additions)

- **Go pins break on a single loop step.** See Gap 3 "Test coupling"; keep step names and the `"$DMG"` literals.
- **Artifact rename half-done.** release.yml names the unsigned artifact at lines 134 and 164; renaming one leaves `download-artifact` failing on the tag.
- **Publish job has no checkout** (Gap 6): `body_path` fails; use `body`.
- **`LSMinimumSystemVersion` greps** (19-05): keep the two-line key/string layout.
- **DR check run on an ad-hoc or `--deep` build** gives `cdhash` DR; the gate only passes on a Developer ID signature, so it can run only in sign-macos.
- **New .sh test changes TESTING.md counts**: build-script group becomes 2 files; traceability row paths must be repo-relative `.sh`.
- **Brand gate** rejects VM-only tags and developer home paths anywhere in tracked files; keep fixtures and docs path-free.
- **Never tag or push a tag** from this phase; a v* tag triggers the real pipeline and a public asset.
