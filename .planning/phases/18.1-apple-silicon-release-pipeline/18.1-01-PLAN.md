<objective>
Make every build Apple Silicon only with minimum macOS 14, and make a PR fail when that regresses (REL-01, ROADMAP SC1). The tracer drives the one local entry point, build.sh, end to end: arm64 Wails build with both CGO minos flags, Info.plist at 14.0, and a new bundle gate (scripts/verify-bundle.sh) that proves the real bundle is arm64-only with minos 14.0. The expansion task tests the gate with compiled fixture bundles and wires build.yml so every push and PR builds the same way and runs the gate.

Output: scripts/verify-bundle.sh, tests/verify-bundle.test.sh, edited build.sh, Info.plist, Info.dev.plist, tests/build-script.test.sh, .github/workflows/build.yml.
</objective>
