## Decisions implemented

CONTEXT [Binding] (connect, then the tab points at the loopback proxy URL; the web view URL never carries the token), [Proxy] (signalling only through the daemon), Local Network decision (costly, accepted; the timeout state with Open System Settings and Open in Browser), post-research hidden-window rule (about 2 minutes) and Phase 19 seams (pluggable connection, pre-redial hook). UI-SPEC toolbar label table, app states table and Copywriting Contract. Research Pattern 4 (refresh before every redial), Pitfall 6, Pitfall 7.

Planner notes (reversible): the first transport defers its WebSocket until the initial connect finishes, because Phase 19's client never runs beforeRedial before the first connect; a failed initial connect still opens the socket when a URL came back, and the proxy's own refusal then drives the client's classification. The Local Network watcher arms on the applied answer rather than on peer-connection creation, so a slow answer is not mistaken for a blocked network.
